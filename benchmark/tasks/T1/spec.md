# T1 精确规格石亭（论文对应：精确规格小屋）

## 验收规则
- 输出必须是 structure.json 超集 JSON（name + items），6 个元件与规格逐条一致；
- 校验器：`benchmark/tasks/T1/validator.ts`（确定性）——GT 由校验器代码生成（与 prompt.txt 逐条规格一致），
  元件规范化（数值吸附 1e-3、盒体绕 Y 90° 等价类）后贪心匹配；
- 头条指标：元件 IoU = 匹配数 / (GT数 + 预测数 − 匹配数)；
- 分解指标：地板/立柱 1-4/屋顶 命中、多余元件数、非轴对齐数、入地数。

## 容错说明
- 位置/尺寸容差 0.02 米（float32 精度回写余量）；盒体绕 Y 的 k×90° 旋转视为等价（方向容错，不算加分）；
- 解析失败（parse_ok=false）记 0 分并注明原因。

## 已知失败模式（对应论文"壳"式缺陷的精确域变体）
- 遗漏立柱/屋顶（规格执行失败）；尺寸写反轴序；多余装饰部件（规格外添加）。
