# T4 自由生成四腿桌（论文对应：自由生成小屋——只给功能要求）

## 验收规则
- 无真值，结构不变量评分（校验器 `benchmark/tasks/T4/validator.ts`，确定性）：
  贴地 / 桌面存在 / 净空 ≥ 0.5 / 四象限支撑（每象限一腿且腿顶贴桌底）/ 对称 /
  比例（腿在桌面外缘内）/ 无穿模 / 结构健康（轴对齐、正尺度、不入地）；多余元件扣分；
- 头条指标：加权和（权重见 validator 源码注释）；
- 每轮每会话跑 2 次取均值（论文教训：小样本方向性，需重复）。

## 容错说明
- 腿 = 竖直长条（y 向 ≥ 0.3 且 ≥ 2×水平向）且贴地；桌面 = 水平平板（长宽 ≥ 0.6、y 向 ≤ 0.25）；
- 容差 0.02~0.05 米按检查项标注。

## 已知失败模式（论文"壳"式缺陷的直接对应）
- 缺腿（<4）；腿不贴地（悬空桌面）；净空不足（腿太矮，人坐不进去）；
- 桌面四角无支撑（腿集中在中部）；不对称；腿超出桌面；腿互相穿插。
