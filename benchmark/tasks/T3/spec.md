# T3 拱桥（规则推导）（论文对应：螺旋楼梯塔——规则推导，不给出总数）

## 验收规则
- 桥面板数 N 由规则推导（3.0 / 0.5 = 6），不写进提示词；
- 校验器：`benchmark/tasks/T3/validator.ts`（确定性）——
  模式与规则一致性：每块板尺寸/高度/网格对齐/无缺口无重叠、覆盖 [−1.5, 1.5]；
  每根柱尺寸/贴地/顶贴板底/位于板心；板-柱双向支撑关系；无多余元件；
- 头条指标：加权 = 0.4·板规则命中 + 0.15·覆盖率 + 0.15·柱规则命中 + 0.2·支撑比例 + 0.1·无多余。

## 容错说明
- 元件规范化同 T1；容差 0.02 米。

## 已知失败模式（对应论文"规则丢失"）
- 板数算错（多/少）；板间距不均匀或留缝；柱顶不贴板底（悬空柱/悬空板）；漏柱；多余装饰。
