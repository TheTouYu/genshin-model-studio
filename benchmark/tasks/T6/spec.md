# T6 摩天轮（复杂自由生成——自创任务）

## 任务性质
- 复杂自由生成任务（无真值）：模型用 gms 组件 API（part: ring/rod/disc/el-disc/arc/plate、rotatem、curve 等）写组件脚本，
  管道（scripts/run-gms-model.sh）执行脚本 → draw-model 生成 items → 落盘 + 网页多视角截图；
- 核验对象：管道生成的 items（确定性产物），不是聊天文本；
- 目的：任务复杂度达到风扇级（环段 ~48×2 + 吊舱 6 + 支架杆等，100+ 元件），
  检验论文范式在"模型需要自主三维推理"场景的价值（论文结论 ② 的领域对应）。

## 验收规则（benchmark/tasks/T6/validator.ts，确定性）
| 检查项 | 权重 | 说明 |
|---|---|---|
| 轮环 | 0.20 | 细圆柱环段 ≥ 16 且角度覆盖 ≥ 270°（按到轮心距离聚类取众数半径 r） |
| 吊舱数量 | 0.15 | ≥ 4（要求 6） |
| 吊舱均布 | 0.15 | 相邻夹角最大 ≤ 90°（理想 60°） |
| 吊舱在轮缘 | 0.10 | 吊舱中心到轮心距离 ≈ r（±0.25） |
| 支架 | 0.15 | ≥ 2 根细长圆柱杆、底贴地、顶端 ≈ 轮心高度、底跨距 ≥ r×0.7 |
| 轴 | 0.05 | 轮心处有短轴元件（无则 0.5） |
| 比例 | 0.10 | 轮半径 r ∈ [0.4, 1.0] |
| 无穿模 | 0.05 | 支架杆与环段/吊舱不重叠 |
| 健康 | 0.05 | 正尺度、无入地 |

轮心推导：支架杆顶端平均（y 取 AABB 顶）；环段/吊舱围绕轮心判定。

## 失败模式（论文"壳"式缺陷的复杂域对应）
- 支架缺失/不贴地（轮悬空）；吊舱数量不足或分布集中；吊舱悬在轮外；轮径过小/支架跨距过窄；
- 支架杆穿轮环；只画轮不画支架（环"壳"）。
