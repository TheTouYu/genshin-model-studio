# T2 变换：旋转 + 平移（论文对应：坐标旋转变换）

## 验收规则
- 输出变换后 3 个元件；校验器对 GT 施加同一变换公式（绕 Y 90° → (x,z)→(−z,x)，再平移 (+1.0,0,−0.5)），
  逐元件核对（位置/尺寸容差 0.02 米）；
- 头条指标：元件 IoU；分解：变换命中率、max/mean 位置误差、多余元件数。

## 容错说明
- 盒体旋转 90° 后的 scale 轴交换由规范化处理（等价类，不算加分）；
- 变换公式逐点核对体现在位置误差：每点必须落在公式结果 ±0.02 米内。

## 已知失败模式
- 只旋转不平移 / 只平移不旋转；旋转方向反（应为 (x,z)→(−z,x)）；忘了交换盒体 scale 轴序。
