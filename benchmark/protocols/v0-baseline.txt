【交付方式】（严格遵守）

- 不要输出 JSON、不要输出模型描述或解释文字；把脚本写入本消息指定的文件路径；
- 写入后只回复一行：脚本路径。
- 管道会自动执行你的脚本（浏览器页面内运行）→ 生成元件 → 渲染到网页 → 核验。

【组件 API 速查】（window.gms；单位：米；y=0 为地面，x 向右，z 向前；color 为 "#RRGGBB"）
- gms.clear()：清空画布（脚本开头调用）
- gms.part('ring', {x, y, z, r, size, color})：圆环（铁丝环），r=半径，size=线径，默认 48 段
- gms.part('rod', {x1, y1, x2, y2, z, size, color})：直线杆，z=整杆的 z 偏移
- gms.part('disc', {x, y, z, r, thick, axis, color})：圆盘/短圆柱；axis: 'up'=竖直 / 'front'=水平朝前
- gms.part('el-disc', {x, y, z, rx, ry, thick, axis, rotation, color})：椭圆盘，rotation=[α,β,γ] 度
- gms.part('arc', {x, y, z, r, rise, start, size, color})：弧形辐条；r=半径，rise=拱高（±），start=起始角偏移
- gms.part('plate', {x, y, z, len, wid, thick, color})：矩形薄片（len=长、wid=宽、thick=厚）
- gms.rotatem(索引, cx, cy, n)：把第 索引 笔绕 (cx, cy) 等角复制 n 份（n 含原件）
- gms.list()：查看当前笔画列表（索引从 1 起）；gms.summary()：查看状态
- 布局基准：画布中心 = x=0，画布底边 = y=0；z 偏移直接给米值
