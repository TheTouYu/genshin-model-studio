【组件 API 速查】（window.gms；单位：米；y=0 为地面，x 向右，z 向前；color 为 "#RRGGBB"）
- gms.clear()：清空画布（脚本开头调用）
- gms.part('ring', {x, y, z, r, size, color})：圆环（铁丝环），r=半径，size=线径，默认 48 段
- gms.part('rod', {x1, y1, x2, y2, z, size, color})：直线杆，z=整杆的 z 偏移
- gms.part('disc', {x, y, z, r, thick, axis, color})：圆盘/短圆柱；axis: 'up'=竖直 / 'front'=水平朝前
- gms.part('el-disc', {x, y, z, rx, ry, thick, axis, rotation, color})：椭圆盘，rotation=[α,β,γ] 度
- gms.part('arc', {x, y, z, r, rise, start, size, color})：弧形辐条；r=半径，rise=拱高（±），start=起始角偏移
- gms.part('plate', {x, y, z, len, wid, thick, color})：矩形薄片（len=长、wid=宽、thick=厚）
- gms.rotatem(索引, cx, cy, n)：把第 索引 笔绕 (cx, cy) 等角复制 n 份（n 含原件）
- gms.list()：查看当前笔画列表（索引从 1 起）；gms.summary()：查看状态
- 布局基准：画布中心 = x=0，画布底边 = y=0；z 偏移直接给米值

【推理步骤】（在脑中完成，不要输出过程；逐步进行，不要跳步）
1. 先规划俯视（XZ 平面）布局：确定每个部件的水平位置与水平尺寸——这是第一张 2D 平面图；
2. 再沿 Y 轴从地面（y=0）向上逐层堆叠：每一层高度区间视为一张 2D 截面；
   层与层之间的衔接是代数规则，不需要心算三维：
   - 贴地规则：最下层部件的底面 = y=0；
   - 支撑规则：每个部件的底面中心必须落在地面（y=0）或下方部件顶面范围内；
   - 相接规则：部件顶面/底面在竖直方向严格相接（差 0 或极小的接触容差），不留空隙；
3. 逐层完成后，把每层 2D 布局翻译成组件命令（gms.part 等，按层分组书写：先底层后上层）；
4. **全组件受力分析（最重要的一步：对每个部件逐一走一遍受力分析）**：
   对模型中的每个部件依次回答：
   a) 它受什么力？——重力（向下）是唯一必须考虑的力；
   b) 它的力从哪里来、传到哪去？——受力必须形成一条从地面向上传导的连续链：地面 → 支架 → 轮毂/轴 → 轮环/轮辐 → 绳索 → 座舱；
   c) 它悬空了吗？——受重力的部件如果下方没有接触面/挂点/支撑件，就是悬空，不合格（绳索本身两端必须都连接物件：上端挂点、下端座舱顶）；
   d) 它和别的部件重叠了吗？——旋转部件（轮环、轮辐、吊舱）有转动路径，任何固定件（支架）不得与转动路径相交，否则转不起来；
   e) 它符合常识吗？——整体看起来像真实摩天轮：轮辐从轴心到轮缘、轮缘有横杆固定两环、绳索竖直绷直吊着座舱、支架四杆斜撑做宽。
   受力链不完整、有悬空、有重叠 → 回到第 1 步重新设计。
5. 输出前按不变量清单自查，逐项核对：
   [ ] 贴地：所有部件底面 y ≥ 0，且该贴地的都贴地；
   [ ] 支撑：没有悬空部件（每个部件底面中心有支撑；悬挂/悬空类结构须由支架等明确支撑）；
   [ ] 尺寸：与任务规格一致（精确任务逐条核对；自由任务核对功能要求）；
   [ ] 无重复、无多余部件。
6. 回退重推：若第 4/5 步任何一项核对失败，不要直接交付——回到第 1 步修正后再写脚本。
