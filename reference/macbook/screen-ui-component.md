# 亮屏桌面组件（可拆分）规格 —— 14" MacBook Pro

> 目标：让笔记本在「开盖 + 亮屏」状态下读出**开机桌面**的细节密度。
> 组件边界：**屏幕活动区内的全部内容**，独立成件、可整体开关，不碰机身骨架。
> 真源：`reference/macbook/screen-ui/screen-ui-layout.mjs`（布局）→ `embed-part.mjs` → `scripts/parts/laptop-screen-ui.js`（可直接跑的 part 脚本）。

---

## 一、选定的画面：macOS 桌面（渐变壁纸 + 菜单栏 + 刘海 + Dock + 窗口 + 光标）

候选对比（按「简单 ↔ 细节密度」权衡）：

| 候选画面 | 件数量级 | 否决/采纳理由 |
|---|---|---|
| Apple 开机 logo + 进度条 | ~6 | 太简单，零桌面语义，不体现细节 |
| 单个 App 窗口（照片网格） | ~40 | 读作「某个 App」，不是「桌面」 |
| 复杂壁纸（Big Sur 波峰 / 照片） | 数百块近似曲线 | 曲线必须靠大量小面拼，成本爆炸，违反「细节=关键点+算法连线」 |
| **macOS 桌面（采纳）** | **40 / 103 / 182** | 全部由**轴对齐矩形 + 规则阵列**构成，可算法生成；细节密度最高 |

采纳的三条硬理由：
1. **真实比例恰好落在引擎可表达区间**（1pt = 2px = 0.2mm）：菜单栏 24pt=4.8mm、Dock 图标 48pt=9.6mm、Dock 高 64pt=12.8mm、窗口标题栏 28pt=5.6mm、交通灯 Ø12pt=2.4mm、菜单字高 ≈2.6mm —— 不需要夸张放大就能建，且全部通过 §三 的长宽比闸。
2. **四层全是参数化阵列**：壁纸=色阶插值循环、菜单栏=文字块循环、Dock=图标网格循环、窗口=缩略图网格循环。加细节不靠手摆。
3. **亮屏信号来自色值对比**，不依赖材质：GIA 无自发光，靠「高明度内容 + 黑边/刘海压边」读出「屏幕亮着」。

## 三、引擎约束（源码实证，逐字遵守）

1. **平面轮廓抽稀 = 长宽比，不是绝对尺寸**
   `adaptiveEpsilon(points) = max(RDP_EPSILON_MIN, diagonal × RDP_EPSILON_RATIO)`
   —— `RDP_EPSILON_MIN = 0.1`（px）、`RDP_EPSILON_RATIO = 0.005`（`src/draw/fitting.ts:14,16,47`）。
   矩形角点到对角弦的距离 ≈ 短边 → **角点保留条件 ≈ 短边/长边 > 0.005（1:200）**，与板厚无关。
   本组件最窄件 = 96 条带壁纸 **3.15 × 196.4 mm = 1:62** ✓（上一轮格栅叶片 0.5mm 失败、1.0mm 成功，正是 1:280 与 1:140 的差别）。
2. **重叠件必须分 z 层**：单块板 `thick = 0.0004` m、层间距 `0.0005` m；**同层内不得重叠**（同 z 共面 → z-fighting），生成器内置同层重叠断言，越界直接抛错。
   四层中心 z（相对屏幕表面，米）：壁纸 `0.0002` → 底件 `0.0007` → 细节 `0.0012` → glyph `0.0017`（**最大凸出 1.7 mm**）。
3. **`part('quad')` 的 x/y/z 是「该块中心」**（`web/index.html:2932-2940`），不是角点；朝向由 `normal` 决定，`rot = [90+δ, 90−phi, 0]`、`δ = −asin(ny)`、`phi = atan2(nz, nx)`。
4. **开合 100° 时上盖内表面法线** = `[0, 0.173648, 0.984808]`（`lidNormal(100)`）。
5. **颜色**：GIA 导出时必须是对象 `{enabled:true, rgb:'0xRRGGBB', opacity:100, overlay:'overwrite'}`（hex 字符串会被拒）。
6. **不要求 `roll`**（未实现）；本组件全部轴对齐，无需平面内旋转。

## 六、挂载到机身（世界坐标）

```js
// 屏幕局部 (u,v) → 世界：上盖方向 u=(0,sinθ,cosθ)、法线 n=(0,−cosθ,sinθ)，θ = 开合角
const v = 0.0096 + (local.y + local.h / 2);          // 活动区下沿距铰链 9.6mm
const u = (local.x + local.w / 2) - 0.3024 / 2;      // 屏幕水平居中于机身中线
world.y = 0.0115 + v * sinθ - z * cosθ;              // z = 该块的层偏移
world.z = -0.1000 + v * cosθ + z * sinθ;             // 铰链枢轴 z = -0.1000
```
数值自检（θ = 100°）：屏顶边 `y = 0.2144`、屏底边 `y = 0.0210`、x 范围 `±0.1512`、z 范围 `−0.1342..−0.1008`、法线 `[0, 0.173648, 0.984808]`。
（`0.2144` 与上轮实测「开盖远端 y = 0.214422」逐位吻合。）

**可拆分约定**：
- 单独 part 文件 `scripts/parts/laptop-screen-ui.js`（自包含，只调 `window.gms.part('quad')`）；
- 顶部常量 `TIER`（`minimal|standard|full`）与 `ANGLE`（默认 100）即开关；
- 主 part 里不要内联桌面件——需要时单独跑一次 runner，产物并入 items。

| # | 判据 | 命令/方法 |

| 1 | 布局自检：无短边 <2.2mm、无长宽比 >1:200、**同层零重叠** | `node reference/macbook/screen-ui/screen-ui-layout.mjs`（越界即抛错） |
