# 14" MacBook Pro 精细建模（v3）—— 参考图驱动 + 亮屏桌面组件

> ⚠ **历史版本 / 可选附录，非当前提示词**：当前提示词是仓库根目录的 `PROMPT-laptop-max.md`。
> 本文件里所有「不得修改 `src/`、`package.json`、`web/index.html`」之类的禁令**已作废**——仓库源码（引擎 / CLI / 预览页 / part 库）可自由修改升级，发现限制就改它。

## 0. 定位句

- **名称**：`laptop-v3`（Apple MacBook Pro 14 英寸，M5 Pro，2026）
- **目标**：使用本项目工具，制作一个 **CG 渲染级别**的笔记本电脑建模 —— **以假乱真：在给定观察距离与角度下，无法分辨这是建模还是真实的 Mac 笔记本**。
- **不是「把尺寸做对」**，而是把**设计语言**做对：连续曲率、缝隙均匀、结构隐藏、栅格对齐；本轮重点补齐**键盘逐键细节**（键帽本体 / 字符层 / 长键平衡杆）与 **logo 等位置的细节层次**。
- **验收锚**：不是「门禁全绿」，而是**同角度 A/B 盲测无可见差异**（判据与协议见 §3）。
- **范围**：整机细节升级 + 新增**可拆分的亮屏桌面组件**；一轮做完，中途不要问我。

## 1. 交付形态锁定（critical）

## 3. 以假乱真门（本轮第一优先级，AGENTS.md 铁律 10）

**规格数值是实现约束，不是设计目标。** 具体数值只锁三类：① 官方公布的整机三围；② 屏幕活动区；③ 引擎阈值（§5）。其余位置（键位、触控板、接口、格栅、脚垫）**一律以官方图逐像素标定为准**，不得沿用上一轮的 13 英寸数据。

**「无法分辨」的观察条件（判据只在以下条件下成立，必须写进交付文档）**：观察距离 **0.5–1.0 m**、视角 iso 30° / 正视 / 侧视 / 俯视、渲染图中模型高度 ≥ 400 px；远景（≈3 m）只验轮廓与色块。

**六项判据（逐项打勾，任一项不达标即未达成"以假乱真"）**：

| 维度 | 判据 |
|---|---|
| 轮廓 | 剪影与参考图叠合误差 ≤ 1 px（参考图分辨率下）；圆角连续、无可见折角 |
| 键位 | 78 键逐键位置/尺寸/字符与 `gen-04` 字符表逐项一致；空格居中；无错位/重键 |
| logo | 尺寸 37.1 × 45.6、上偏 4.1 mm、镜面明度对比与官方俯视图一致 |
| 接口 | 开口位置/宽高/内腔层次与官方侧视图一致 |
| 缝隙 | 可见缝隙 ≤ 0.5 mm 且**均匀**（同一条缝宽度差 ≤ 0.1 mm） |
| 色值 | 同一零件单一表面处理；键帽 / 掌托 / 上盖三色可辨、同类一致 |

**A/B 盲测协议（必须实跑，结果写进 `A-B-对照.md`）**：取 6 张自渲染图 + 6 张参考图（官方图 + `gen-0*`）混排为 12 张、文件名去标识，交给独立模型判定每张是「建模渲染」还是「真机照片」——命令 `python3 ~/.agents/skills/isolated-model-evaluator/scripts/evaluate.py --task-file <task.md> --provider aijws --model gpt-5.6-sol --tools read,bash --output-dir <dir>`；**误判率 ≥ 50%（随机水平）即视为达到"无法分辨"**，并附完整误判矩阵。

**不可达维度（引擎不支持，必须在交付文档显式声明，不许含糊带过）**：材质反射率 / 粗糙度 / 金属度（无 PBR）、真实光照与阴影 AO、屏幕像素级内容（只能块面近似）、真圆连续曲率（折线逼近，弦高 ≤ 0.5 mm）。

- **尺寸基准（真机）**：整机 **312.6 × 221.2 × 15.5 mm**；屏幕活动区 **302.4 × 196.4 mm**（3024×1964，254ppi）；四角圆角 **R ≈ 20 mm 且四角一致**；上盖厚约 4 mm。
  > 上轮用的是 304 × 212 × 15.5 —— 那是 **13 英寸 MBP 2020** 的三围，与 14 英寸键位混搭成的「不存在的机型」。**本轮必须改**。
- **必须先写** `DESIGN-LANGUAGE.md`：连续曲率、缝隙均匀、结构隐藏、栅格对齐 —— 每条写出**本模型的判定方法**（可复算的数字或可对照的图），不是口号。
- **必须做同角度 A/B 并排**：自渲染图 vs `gen-01` 与官方图，逐项打勾写进 `A-B-对照.md`。
- **上轮实测的高频破绽，逐条自检并给出实测值**：方角穿出圆角包络（4.14 mm）、板角穿出圆角管（2.14 mm）、圆角管平头接缝（0.32 mm）、转轴端头与侧壁齐平（Ø4 mm 外露）、盖板高出台面（0.6 mm）、上盖后缘穿入机身（6.60 mm）、键位语义错误（空格键 x=+0.0950 且间隙 0.0040 与邻键 0.0006 不一致）。
- **门禁全绿 ≠ 像**：`DELIVERY-v3.md` 里的 `pass` 必须紧邻一行「未覆盖维度：设计保真（无参考图对照）」，或给出对照结论。

## 4. 细节清单（11 项，按优先级）

- **D1 屏幕内容** → 由 **D11** 承接，不再单独做渐变。
- **D2 键帽（本轮重点，按 `gen-04` 的结构层次逐件做）**：
  - **硬约束（官方实测，优先）**：键距 **19.05 mm 列 × 18.5 mm 行**（行距 = 列距 × 0.973，两路独立互证）；**空格键 5u ≈ 92.5 mm**（比标准 ANSI 6.25u 短 25.5 mm）；空格键中心 = 键盘块中心。
    > `gen-04` 给的 114.00 mm 空格与 ≈16.8 mm 绘图间距是**标准 ANSI 通用值**，与本机型不符 → 一律以官方实测为准。
  - **D2a 键帽本体**：顶面 **14.00 × 14.00 mm**、厚 **1.20 mm**、顶面圆角 **R1.00 mm**、**双曲面**（X 向 R300 / Y 向 R400，用细分表达，**禁止 jitter 扰动**）；4 侧斜壁连续、上小下大；微磨砂哑光。
  - **D2b 字符层**：每键 1–4 块 **0.10 mm** 深/透光条，按 `gen-04` 的逐键字符表（六行，从左到右、从上到下）；白字黑帽（背光透光）；**字符不得用随机色块近似**。
  - **D2c 长键**：左 Shift 53.00、右 Shift 65.00、Return 48.00 × 29.00、Tab 28.00、Delete 28.00、Caps Lock 41.00、方向键 14.00 × 14.00（高度均 14.00）；底部 **2–3 个固定点 + 钢丝平衡杆卡扣**。
  - **D2d 键底结构（近景档，可选）**：键底 13.60 × 13.60、剪刀脚安装位、稳定柱 Ø2.00、定位柱、透光孔——仅当 A/B 对照显示近景可见时才做，并报件数。
  - **颜色**：键帽深空灰（Pantone 426C，近似 `#25282A`）；字符白色透光。
  - **产出**：`KEYBOARD-LAYOUT.md` 逐键坐标表（键位 / 中心 x,y / 尺寸 / 字符 / 件数），供逐键核对。
- **D3 四角圆角**：每角 **3–4 段折线**逼近 R 0.0200，弦高误差 ≤ 0.0005。
- **D4 接口**：USB-C 做内腔（底板 + 3 壁 + 舌片）、耳机孔做内圈；接口**齐平内嵌不凸出**；位置按官方左右侧图逐像素标定（左：MagSafe + 2×USB-C + 耳机孔；右：HDMI + USB-C + SD 卡槽）。
- **D5 散热格栅**：叶片加密到视觉连续；厚度先算 §5 的长宽比闸。
- **D6 转轴**：圆柱分段 ≥ 5 段；**轴端内缩 ≥ 1.5 mm**（不许与侧壁齐平）；铰链盖与机身缝隙均匀。
- **D7 底面**：铭牌位 + 序列号槽 + 扬声器孔阵列（≥ 6 孔）+ **4 个 Ø15.0 mm 脚垫**（距左右边 22.0 mm、距前后边 22.7 mm）。
- **D8 触控板**：凹陷边框（四侧壁）+ 材质色差；**触控板是平的**（Force Touch 无机械行程），只靠玻璃面 vs 喷砂铝的反射率差异区分；尺寸按官方图标定（≈130–132 × 79 mm 量级）。
- **D9 摄像头**：刘海内的方形孔圈（外框 + 内芯）+ 状态点。
- **D10 logo（重点，此前细节不足）**：上盖外表面**居中偏上**的镜面 Apple 标志 —— **37.1 × 45.6 mm（含叶）**、水平居中偏差 ≤ 0.2 mm、中心在上盖几何中心**上方 4.1 mm**（14" 按上盖宽比例 ≈0.88× 或按官方图逐像素标定）。
  - 结构：**独立镜面嵌件** + 轮廓缝隙 ≤ 0.10 mm + 与上盖共面（微凹 ≤ 0.05 mm）；叶与果体分件、曲率连续（折线逼近弦高 ≤ 0.0005）。
  - **镜面只能靠高明度对比色值表达，不许用几何做镜面**；与官方俯视图同角度 A/B 比对轮廓与位置。
- **D11 亮屏桌面组件（可拆分）**：屏幕活动区内铺 macOS 桌面——渐变壁纸 + 菜单栏 + 居中刘海 + Dock + 窗口 + 光标。

  - 硬性要求：全部 `10009003`；四层 z（0.0002 / 0.0007 / 0.0012 / 0.0017）；**同层零重叠**；开盖法线 `[0, 0.173648, 0.984808]`；屏顶边 y = 0.2144。
  - 视觉基准：`reference/macbook/screen-ui/preview-full.png` + `gen-02` / `gen-03`，三者同角度比对。
- **D12 其他位置细节清单（逐位置，缺一项即未完成）**：

  | 位置 | 层次 / 数值 | 依据 |
  |---|---|---|

  | 扬声器点阵竖带 | 键盘左右各一条、贯穿键盘高度；**多为装饰孔（不通透）** | 官方维修图 |

## 5. 引擎硬约束（全部实跑/源码验证过，违反即报错）

- **导出主链**：`npm run export-mesh` `--` `exports/laptop-v3/laptop-structure-in.json` `--out-dir` `exports/laptop-v3` `--format` `both` `--force` `--no-qa`
  - 必须带 `--`：npm 会吞掉自己不认识的 `--format`（实测 `Invalid abbreviated flag "--format"`，exit 1）。
  - `--format both` 补出 `.gil` 供回读；`--no-qa` 因纯 quad 透传下 `summary.budget.used = 0` 必然误报（实测），**理由必须写进 `s4-verify.json`**。
- **part 运行**：`bash scripts/run-gms-parts.sh <out> <part.js>…` —— 脚本**无执行位**（`-rw-------`），必须 `bash` 调用；运行器取**浏览器第一个标签页**，运行前浏览器必须停在 `http://localhost:8787/` 建模页（否则 `PART_EXEC_ERROR: gms is not defined`）。
- **平面轮廓抽稀 = 长宽比，不是绝对尺寸**：`adaptiveEpsilon = max(0.1px, 0.005 × 该笔画自身包围盒对角线)`（`src/draw/fitting.ts:14,16,47`）→ 矩形角点保留条件 ≈ **短边/长边 > 0.005（1:200）**，与板厚无关。细节件先算这个比再定尺寸。
- `quad` 只有矩形（真圆用 `disc` / `el-disc`）；`roll` 未实现 → 确需平面内旋转用 `gms.props` 覆写该 item 的 rotation。
- `disc` / `el-disc` 的 `lift = y − thick/2` **必须非负**；横向长圆柱（转轴）用 `rod`（只读 `x1/y1/x2/y2` + **单值 `z`**，`z1/z2` 被忽略）。
- 可见缝隙 ≤ **0.001 m**（引擎接触判定 `contact: gap <= 0.001`，`web/index.html:3127`）；`gms.touches` 对 quad 用 AABB 且**忽略 normal**（假阳性与假阴性并存）→ 必须另做独立 AABB 复算。
- root 0.1 由导出主链内部 `makeGiaInput` 施加（`src/cli/export-mesh.ts:319`）；`/api/export` 不施加，**不得当 root 证据**。
- 表面一律 `10009003`；**禁止** `10009001` 盒做表面、**禁止** `10009019` 网格直出 `.gia`；不规则必须来自细分，**禁止** jitterMesh 随机扰动。
- 细节 = 关键点 + 算法连线，**禁止贴小方块/小柱子式假细节**；先补工具原语再上算法。

## 6. 验收标准（逐条可核对）

- **尺寸**：整机 312.6 × 221.2 × 15.5 mm（误差 ≤ 0.002 m）；顶面水平、前后厚度一致；开合 100° ± 2°（上盖远端 y ≈ 0.2144，按真机尺寸重新推导）；四角圆角一致。
- **以假乱真**：§3 六项判据逐项打勾 + **A/B 盲测误判率 ≥ 50%**（附完整误判矩阵）；§3 七类破绽全部给出实测值且不超限；不可达维度已显式声明。
- **结构**：`gms.verify()` ok、`gms.floating` 空、`gms.collides` 空、links 全接触；独立 AABB 复算 0 孤立件、应贴合对 0 缝隙、**上盖件 vs 底座件 0 穿模**。
- **视觉**：六视角（`--views` iso,top,front,left,right,closeup）非空且互不相同，`read_image` 逐张复核；独立视觉复核 `python3 ~/.agents/skills/isolated-model-evaluator/scripts/evaluate.py --task-file <task.md> --provider aijws --model gpt-5.6-sol --tools read,bash --output-dir <dir>` 无阻断项，**任务文件必须带参考图与检查清单**。
- **导出**：退出码 0；四件齐备；`python3 tools/gia/gia_parser.py <gia> --json <outfile>` 读出 `versions[0].data.rootTransform.scale` ≈ [0.1, 0.1, 0.1]（`--json` 必须带输出文件名）。
- **细节**：D1–D12 逐项在 `DELIVERY-v3.md` 写「做了 / 为何没做」+ 截图路径；D2 另报**逐键件数**（键帽 / 字符层 / 长键分列）、键距实测、空格键宽度实测；D10 报 logo 尺寸与上偏实测；D11 另报实际件数、同层重叠检查结果、开盖法线与屏顶边 y 实测值。
- **终验（唯一人类门）**：用户进游戏实测并签字。

## 7. 排除项（不要什么）

不要宣称达到 PBR 级材质 / 真实光照 / 阴影 AO（引擎不支持，只能用几何 + 色值模拟）；不要用「渲染图看着不错」当验收信号；不要直接缩放上轮坐标糊过去；不要用 `gen-04` 的通用键距 / 114 mm 空格覆盖官方实测（键距 19.05 × 18.5、空格 5u 92.5 是硬约束）；不要用随机色块近似键帽字符；不要用几何做 logo 镜面；不要覆盖 `exports/laptop/`；不要随机扰动造细节；不要贴小方块/小柱子式假细节；不要 mesh 面板化路线；不要 `10009001` 盒体表面、不要 `10009019` 网格直出；不要引入第三方依赖（**仓库源码可自由修改升级，不受限**）；不要跳过门禁；不要一次性画完（必须分阶段留证据）；不要在无截图证据时宣称完成；除「游戏实测签字」外不要向我提问。

## 8. 输出协议

- 每阶段**直接输出**：阶段名 / 命令原文 / 产物绝对路径 / 自检读数；**不要附加**解释性散文。
- 失败时只报三行：错误原文 + 修复动作 + 复验命令。
- 收尾输出交付摘要：`itemCount`、资源分布、`.gia` 字节、尺寸实测值、门禁结论、A/B 对照结论、截图清单，以及一句「未获用户游戏实测签字，不得宣称完成」。
