## 二、图集清单（9 张，缺一不可）

### A1 · 正交三视图（俯 / 前 / 侧）★最关键
- **构图**：三视图并排，同一比例，正交投影（无透视），白色背景，细灰尺寸箭头 + 数值标注。
- **必须出现**：圆角轮廓四角一致；闭合态上盖/底座缝隙均匀；前缘居中开盖凹槽；左右侧接口位置正确。
- **禁止**：透视变形、楔形机身（前端薄后端厚）、方角、可见螺丝、logo 错位。
- **附加**：另出一张同构图的**纯线稿版**（白底黑线，无材质），供建模对轮廓用。

### A2 · 键盘俯视特写（45° 俯视 + 正俯视各一）
- ANSI 78 键；12 个全尺寸功能键；**空格居中**；底排 = fn / control / option / command / 空格 / command / option / 方向键簇（倒 T）；
- 键帽黑色、顶面平、四角小圆角、行列严格对齐、间隙全域一致（≈0.5 mm）；
- 右上角 Touch ID（与功能键同排，略高）；触控板居中、与空格键对齐，边缘小圆角、略低于掌托平面。

### A3 · 底盖俯视
- 四只脚垫：小而内缩（距四角 ≈20–30 mm），嵌入底盖、微凸；**无可见螺丝**；
- 底盖轮廓与上盖同一条圆角折线；侧面可见散热槽靠转轴端。

### A4 · 左侧接口特写（银 + 深空黑）
- 前→后：MagSafe 3（可见 6 触点）→ USB-C ×2 → 3.5 mm 圆孔；后段细长散热槽。
- 开口共一条水平中线；开口边缘为精细圆角倒边，**不是方孔**。

### A5 · 右侧接口特写（银 + 深空黑）
- 前→后：HDMI → USB-C → SDXC；后段细长散热槽。

### A6 · 转轴区微距（后缘 45° + 正侧）
- **转轴不可见**：轴心沉入机身内部、被后缘盖板遮住；**看不到轴端面**（v2 破绽：侧壁一个 Ø4 mm 灰圆）；
- 上盖后缘不得穿入机身；铰链盖与掌托齐平。

### A7 · 刘海 + 屏幕微距
- 屏幕顶边居中黑色矩形刘海，宽 ≈1/8 屏宽，内含 1200 万像素摄像头（居左）+ 指示灯；
- 屏幕活动区四角为圆角；黑边极窄等宽；屏幕表面哑光（非镜面反光）。

### A8 · 开合姿态（100°）+ 品牌细节
- 开合 100° 侧视（闭合 15.5 mm 与开合姿态分开出图，**不要在同一张图里同时要求两个高度**）；
- Apple logo 微距：镜面（深空黑机型对比最强），叶片与果实比例正确、居中。

### A9 · 亮屏桌面（屏幕内容特写，正对屏幕 1:1 构图）
- **只出屏幕活动区**（302.4 × 196.4 mm，比例 1.5395:1），不要机身边框、不要透视、不要反光；
- 内容 = macOS 桌面：顶部菜单栏（高 4.8 mm）+ 居中黑色刘海（40 × 6 mm）+ 左下到右上的深蓝→浅蓝渐变壁纸 + 底部 Dock（高 12.8 mm，12 个 9.6 mm 圆角图标：访达/启动台/Safari/邮件/地图/信息/照片/日历/备忘录/音乐/App Store/系统设置）+ 左侧一个白色窗口（140 × 90 mm，标题栏 5.6 mm 含红黄绿三个 2.4 mm 圆点、左侧 22 mm 侧栏、右侧 5×3 缩略图网格）；
- 颜色是**纯色块**（无渐变外的纹理、无图标内部照片级细节）——建模要用平面元件复刻，允许简化但要能辨认图标；
- 亮度：壁纸为高明度（顶区 #8FD6F7 级），黑边与刘海压边形成「亮屏」对比。
- **本仓库已自产 1:1 参考图**：`reference/macbook/screen-ui/preview-full.png`（可直接用作并排比对基准；A9 出图与它逐项对齐即可）。
