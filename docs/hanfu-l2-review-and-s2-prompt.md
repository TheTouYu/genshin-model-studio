## 6 S2（L3）任务书：结构补全 → 算法升面

### 6.1 目标

在 258 面骨架上，把「让它成为甘雨」的**四件结构**补齐（**≤600 面**、仍手控点/面），
再交给算法升面（S3，600 → ~2000，Catmull-Rom + dense/adaptiveAngularStops）。
输入真值、素材权限排序、ESM 消费方式（`await import('file:///…/scripts/parts/lib/ganyu-anatomy-cage.js')` 后取 `globalThis.*`）
**全部沿用 `docs/hanfu-s1b-agent-prompt.md`**，不重复。

### 6.2 四件必补结构（按气质权重）

1. **头/颈/回眸**（最重）：颈部 ≥2 环；头部 yaw 取原图实测**面部对相机 22.4°**；下颌线 + 发际 + 发冠三点定位；发束 ≥2 条主干（前束/后束），流向沿用 142°。
2. **裙摆分层**：外纱 / 中裙 / 内裙 **≥3 层独立环**，层间下垂差 ≥0.08m，单向流 175°（±10°）；**禁止单锥**。
3. **腰封 + 肩饰宝石挂带**：腰封环 1 道；肩饰宝石 ≥4 点 + 挂带 ≥2 条——**从主干 extrudeRing/branch 长出**，禁止贴小件（AGENTS.md 铁律 9）。
4. **剑**：柄 / 护手 / 刃 **三段**（当前只有一根刃杆），长度按原图 px→m 换算（刃长、柄长、护手宽各出数）。

### 6.3 门（L3-G1 … L3-G7）

| 门 | 判据 | 核对方式 |
|---|---|---|
| L3-G1 逐点 3D | 每视图 ≥20 点，X/Y/Z 偏差 ≤2% 身高；三视图剪影 **IoU ≥0.88** | 脚本实测数字 + 叠图 |
| L3-G2 回眸 | 网格 head_yaw 与实测 22.4° 差 ≤3°；reference-view 目检「能看出头转向 + 下颌线」 | 数值 + read_image |
| L3-G3 裙分层 | ≥3 层独立环；层间下垂差 ≥0.08m；流向偏差 ≤10° | 站表数值 |
| L3-G4 拓扑 | openEdges=0 / seamEdges=0 / components=1 / 共享顶点；面数 ≤600 | 报告原文 + 独立 Euler |
| L3-G5 自交债 | 自交=0、瘦三角 ≤5%、面积比 ≤20 | `verifyMesh` 输出原文 |
| L3-G6 剑三段 | 柄/护手/刃齐备，尺寸 px→m 换算留数 | 站表 + 目检 |
| L3-G7 证据链 | `iteration-records/37-*.json` + 5 视角（含 smooth 渲染，**每张都有结论**）+ 叠图 + 独立 mesh 文件 | 盘档 |

### 6.4 交卷格式

1. 逐门一行：门号 / 实测数字 / 判据 / **盘档引文**（R1）。
2. 五视角截图目录，**每张**一句话 read_image 结论（含 smooth 渲染）。
3. 产出**独立 mesh 文件**（`delivery/hanfu-cage/cage-mesh.json`，含 `vertices`/`faces`）供升面算法直读——本轮网格内联在记录里，算法消费不便。
4. 偏差清单：凡未达标项按 `id/item/detail/impact` 四条写全（本轮 D1–D5 格式合格，照抄）。

### 6.5 禁止项

- 禁止贴小件 / index 合并 / A-pose 站桩 / 单锥裙 / 对称站桩 / 外卷上翘角 / 羽片肩饰 / 紫蓝眼色（原图优先清单）。
- 禁止「先升面再补结构」的逆序施工（AGENTS.md 铁律 8）。
- 禁止未过 L3-G5 就升面。

### 6.6 下一轮预告（S3）

L3 全门通过后：算法升面 600 → ~2000（Catmull-Rom + dense/adaptiveAngularStops）→ 生理特征（面部平面/手指根点/锁骨-肩峰-腋窝）→ 材质分带（外纱透明感 / 金饰 / 蓝白渐变）→ 场景 blockout（亭子曲面飞檐 / 山 / 前景花枝 / 雾景深）。
