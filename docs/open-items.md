## 十二期完成（2026-08-14）：外环同面 + 后罩连接 + 外环 48 点 + 叶片桨距角 12°

视觉核验闭环（首验 gpt-5.6-sol 发现 7 缺陷 → 修复 → 数据核验全过 → 复验代理截断但关键点已确认）：

1. **外环/辐条/支架同面 z=-0.04**：原外环 z=0、辐条/支架 z=-0.08 → 环与辐条轴向断开 ~5cm（首验"高"缺陷）；统一后同面连接；与叶片盘 z=0 间隙 3.9cm，不触发旋转组扫掠冲突
2. **后罩 z=-0.10 → -0.085**：与电机后表面（z=-0.085）相接，消除 7.5mm 间隙
3. **外环 24 → 48 点**：RDP 后 32 段 → 段数翻倍，多边形观感消除（首验"中"缺陷）
4. **叶片桨距角 12°**：源 transform.rotation=[102,0,0]（绕长轴=世界 X），副本经 makeRotationCopies **四元数通用化**继承（闭式 [90+θ,90,90] 只是 Rz(-θ)·Rx(90) 特例，矩阵等价已验证）；API 实测副本 rotation=[-29.3,±103.8,±83.2] 与数学预测一致
5. 电机-叶片 4mm 间隙保留（旋转件工程间隙）；支架穿底座 10mm 接受（插入>悬空）

**代码改动**：web/index.html makeRotationCopies（THREE 四元数，无 THREE 或源无 rotation 时退回闭式）；scripts/draw-fan.js 重写（环 48 点 loop + 同面 z + 桨距角）。**铁律 #5 延伸**：改 draw-fan.js 后必须核对 rotate 索引——本轮外环改 loop 后笔画序不变（0 环/1 辐条/5 电机/6 后罩/7 叶/10 支架/11 底座），rotate(1,..,4) 与 rotate(7,..,3) 仍正确。

## 工具/流程缺口（下次会话避免重踩）

| 缺口 | 现象 | 规避 |
|---|---|---|
| **沙箱 /tmp 隔离** | bash 工具命令产物（截图/日志）写入 /tmp 后跨命令/跨沙箱不可见，核验代理读不到主会话截图 | 产物一律放工作区（如 .bh/）；capture-views.sh 的 OUT 参数指向工作区 |
| **browser-harness daemon 需要写 ~/.config** | 沙箱只读 → daemon 起不来 | export BH_HOME=<workspace>/.bh（daemon socket/runtime/.env 全在 .bh，BU_CDP_WS 写 .bh/agent-workspace/.env） |
| **pi CLI 需要写 ~/.pi/agent** | 沙箱只读 → credential 读取失败、evaluate.py 静默失败（仅 exit 1 + 空目录） | evaluate.py 需 danger-full-access 提权；output-dir 放工作区（提权进程的 /tmp 与主会话隔离） |
| **run_code bash 工具 heredoc 异常** | 命令内嵌 <<'PY' 时无输出/静默失败 | 脚本文件内 heredoc 正常（capture-views.sh 等照常）；直接命令改用 printf 管道喂 stdin |
| `inspect-draw-model.sh` tab 匹配 | 匹配"第一个含 8787 的 tab"，若 preview-demo 页在前会拿到无 gms 的页面 | 先切到主页 tab 或给脚本加 exclude 参数 |
| 批量 edit 原子失败无提示 | 一条 oldText 不唯一 → 整批不应用 | 改完 grep 验证每个改动点（复盘铁律 #4） |
| dist/ 手写文件被 tsc 覆盖 | server.js 的修复随 build 丢失 | 手写服务代码放 scripts/（复盘铁律 #3） |
| **视觉核验代理偶发截断** | 207s/8 turns 后 final.md 只写开头（中途状态），重跑一次 50% 概率 | 任务文件要求"先写报告标题再干活"；截断时以数据核验 + 已确认段落为准，不盲目重跑 |
