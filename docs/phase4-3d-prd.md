# 四期：3D 画线建模 PRD

状态：已拍板 · 2026-08-12 · 任务 J/K 开工中
目标：补齐"画线建模"的 3D 缺口——几何工具（解决手抖/精确性）+ 柱体渲染器（轮廓→实体），覆盖水杯/手机/电风扇等日常物件建模。

## 1. 产品形态

**一句话**：俯视/正面视图画"草图"，线条可识别为 杆（线）或 柱体（实体），多笔画组合 + 高度定位 + 旋转复制 → 完整 3D 模型。

**硬约束**（元件库决定）：无任意三角面片/布尔运算 → 输出哲学 = 离散段组合（杆环、柱体、线框），连续曲面/真空腔做不了；游戏级外观表达足够（水杯=杯身圆柱+杯口环+杯底+把手杆，俯视可见环形=空心感）。

## 2. 用户场景剧本（验收基准）

### 2.1 水杯
```
圆工具：圆心+半径 → 圆 A → 弹层：柱体、方向=竖直、高度 8cm、z=0   → 杯身
圆工具：小圆 → 柱体、竖直、高度 0.5cm                            → 杯底
圆工具：中圆 → z=8cm → 杆环（默认渲染）                          → 杯口
曲线工具：3 点 + 完成 → 杆、粗细 3mm                              → 把手
```
### 2.2 手机
```
矩形工具：对角两点 → 圆角忽略 → 柱体、竖直、高度 0.8cm            → 机身
直线/曲线工具：屏幕细节线 → 杆（z 抬升 0.1cm）                    → 屏幕线条
```
### 2.3 电风扇
```
圆工具：大圆 → 杆环（默认）                                       → 防护罩外环
直线工具：中心到环边 1 条 → 旋转复制（中心=圆心，份数 4）           → 罩子辐条
圆工具：小圆 → 柱体、方向=水平、厚度 3cm                          → 电机
自由笔：一笔叶形（闭合）→ 柱体、方向=水平、厚度 2mm               → 叶片
旋转复制：中心=电机圆心，份数 3                                   → 三片叶片
直线工具：电机中心竖直向下 → 杆、粗细 4mm                        → 支架
椭圆工具：扁椭圆 → 柱体、方向=竖直、厚度 1cm                      → 底座
```

## 3. 工具设计（web/index.html 工具栏）

| 工具 | 操作 | 生成 | 适用 |
|---|---|---|---|
| 🖊 自由笔 | 拖拽 | 拟合平滑曲线 | 有机形状（叶片/装饰），手抖由 Chaikin 抹平 |
| ⬜ 直线 | 点两点 | 直线 | 支架/辐条 |
| 🌀 曲线 | 点 N 点（实时预览）+ 双击完成 / 勾选闭合 | Catmull-Rom 样条等距采样 | 把手/叶片轮廓/任意曲率（取代"圆弧工具"） |
| ⭕ 圆 | 点圆心 + 拖半径 | 等距点圆 | 杯口/电机/底座 |
| ▭ 矩形 | 对角两点 | 矩形（圆角忽略） | 手机机身 |

曲线工具算法：**Catmull-Rom 样条**（经过所有控制点、局部控制、C1 平滑），不用高次多项式插值（龙格振荡）。闭合时首尾平滑衔接。采样密度按弦长自适应，输出与自由笔同构的笔画点序列，**后端拟合管线零改动**。

## 4. 数据契约（作品 JSON v3）

```ts
// Stroke v3 增量字段（v1/v2 兼容读入，缺省即旧行为）
export type Stroke = {
  id: string
  points: [number, number][]      // 画布坐标（不变）
  color?: string                  // 三期
  render?: 'rod' | 'solid'        // 缺省 = 跟随全局 mode（extrude=rod / lathe 旋转）
  height?: number                 // 该笔画整体抬升高度（米，沿模型 Y），缺省 0
  axis?: 'up' | 'front' | 'side'  // 柱体轴向：up=竖直(Y)/front=面向观察者(Z)/side=侧向(X)；缺省 up；仅 render='solid' 有效
}
// 作品 JSON v3：{ version: 3, strokes, options, layers? } —— layers 预留不实现
```

规则：
- `render='solid'` 与全局 lathe 模式并存时：solid 笔画渲染柱体，其余笔画照旧 lathe（互不干扰，文档写明）
- `height` 作用于该笔画所有输出 item 的 position.y（杆/柱体/环都生效）
- API 契约（/api/draw-model 请求/响应）不变，仅字段透传

## 5. 后端设计（src/draw/）

### 5.1 spline.ts（新模块）
- `catmullRom(pts: [number,number][], closed: boolean, samplesPerSeg: number): [number,number][]`
- 经过所有控制点；闭合时环绕；单元测试：过点性、闭合平滑性、采样均匀性

### 5.2 solid 渲染器（generate.ts 增量）
- 输入：封闭笔画（已由现有 closed 检测识别）
- 形状识别 → 元件映射：

| 识别形状 | 元件 | 备注 |
|---|---|---|
| 圆（半径方差 < 阈值） | 10009008 圆柱 | scale=[直径, 高度, 直径] |
| 椭圆（宽高比 > 1.1） | 10009008 圆柱 | scale 非等比 |
| 矩形（4 顶点、角近似 90°） | 10009001 长方体 | scale=[宽, 高, 深]；圆角忽略 |
| 其他（三角/五边/任意） | 不支持 → 后端 400 明确提示（一期） | 后续增强 |

- **朝向**：axis='up' 默认；'front' 绕 X 转 90°（轴向 Z）；'side' 绕 Z 转 90°（轴向 X）。**欧拉角顺序必须与现有 rotation 约定一致**，用"方向向量→欧拉角→回读方向"单元测试锁定（3D 双轴组合是首个真正考验）
- 位置：轮廓包围盒中心 → position；height → position.y 抬升
- 非封闭笔画 render='solid' → 400 提示"柱体需要封闭轮廓"

### 5.3 回归保证
- 单层 z 无关笔画（render/height/axis 全缺省）输出与二期**逐字节一致**（golden 兼容测试）
- 现有 29 测试全绿

## 8. 决策记录

- 曲线 = Catmull-Rom（经过控制点），不用泰勒/拉格朗日（振荡）
- 叶片 = 自由笔 + 平滑（有机形状归自由笔；一期为扁平薄片近似，扭曲曲面不做）
- 多边形柱体一期不支持（圆/椭圆/矩形覆盖全部用户场景）
- solid 与 lathe 并存规则：solid 笔画独立渲染
- 轴向参数三个选项（竖直/水平/侧向），默认竖直（水杯直觉）

## 9. 风险

1. **欧拉角顺序**：3D 朝向必须用测试锁定（现有只验证绕 Z）
2. **矩形识别**：用户手绘/矩形工具边界噪声 → 识别容差要稳（先按矩形工具生成规整点，容差宽）
3. **体量**：旋转复制 + 多层会增元件数（count 上限 5000 内测试）
4. **lathe 全局模式 + solid 笔画**的共存边界要写测试
