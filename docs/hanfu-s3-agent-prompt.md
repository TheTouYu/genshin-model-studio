## 6 S3（L4）任务书：薄片化 + 头部块面

### 6.1 目标与预算

在 564 面水密骨架上，用**薄片面片**补齐参考剪影的翼状区域与裙层，并给头部加下颌线环 + 面部块面。
**面数预算 ≤1200**（当前 564）；仍**手控点/面**，**不升面**（升面留到 S5 算法拟合）。

### 6.2 四类薄片 + 头部块面（按 IoU 收益排序）

1. **袖片**：左右各 ≥1 片，从袖根环 `extrudeRing` 长出；片宽/外缘按 L1 实测像素；边缘下垂角照原图。→ 直接补蓝色翼区。
2. **纱片**：外层裙/披纱 ≥3 片，从腰/臀环长出；层间下垂差沿用 **0.250m / 0.160m**；片厚 0 或 ≤0.004m 薄挤出。
3. **发片**：前/后各 ≥2 片（发束改片），流向沿用实测（154°/142°）；片宽按 L1 发束轮廓。
4. **剑刃**：刃改薄片（当前是细柱），护手宽度/柄长按 697.5 px/m 复核；流苏可留到 S5。
5. **头部**：**下颌线环** + 面部块面 ≥3 块（额/颊/颌）+ 眼窝凹陷（不描五官），目标=reference-view 目检「能看出头转向 + 下颌线」。

### 6.3 门（L4-G1 … L4-G8）

| 门 | 判据 | 核对方式 |
|---|---|---|
| L4-G1 剪影 IoU | front/back ≥0.85、side ≥0.78（终态仍 ≥0.88）；三视图叠图必交 | 脚本读数 + iou 叠图 |
| L4-G2 逐点 3D | ≤2% 身高（当前 1.944%，**不得回退**） | g1-3d-report |
| L4-G3 回眸目检 | reference-view 能看出头转向 + 下颌线 | read_image 结论 |

| L4-G5 自交债 | 自交=0、瘦三角 ≤5%、面积比 ≤20（**薄片最易自交**） | `verifyMesh` 原文 |

### 6.4 交卷格式

1. 逐门一行：门号 / 实测数字 / 判据 / **盘档引文**。
2. 六视角截图，每张一句 read_image 结论。
3. IoU 三视图叠图（绿交集/蓝参考独有/红模型独有）+ 逐项归因。
4. 偏差清单 `id/item/detail/impact` 四条（照 L3 格式）。
5. 独立 mesh 文件更新 `delivery/hanfu-cage/cage-mesh.json`。

### 6.5 禁止项

- **禁管体冒充薄片**：袖/纱/发/刃必须是片（可用片厚 0 双面），不得用细管/阶梯半径顶替。
- **禁独立 mesh index 合并**：薄片必须从主干 `extrudeRing`/branch 长出（保持单件水密）。
- **禁贴小件**：宝石/挂带/流苏等细节从主干长出，禁止另贴方块。
- **未过 L4-G5 不交卷**（薄片自交率最高，先清再交）。
