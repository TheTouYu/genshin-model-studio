# MacBook Pro 14" 以假乱真 —— 自定评分表（内部标准，最高档）

> 目的：把「世界级的像」写成可判定、可复测的 7 类。每轮自评，任何一类未满分即回炉。
> 判据全部是**可测量**的：要么机器读数，要么同角度 A/B 盲测统计。

## 评分表（7 类）

| # | 类别 | 满分判据（可测） |
|---|---|---|
| **C1** | **形体与比例** | ① 同角度剪影 IoU ≥ **0.985**（vs 官方参考图，自动对位后）② 关键尺寸误差 ≤ **0.2 mm**（31.26×22.12×1.55 cm 机身、R20 圆角、上盖 4.0 mm、屏幕活动区 302.4×196.4 mm）③ 设计保真 10 条断言全绿且余量 ≥ 2×（方角越界 ≤0.05 mm，非 0.2）④ 单一轮廓：全部水平截面共用同一条圆角矩形折线 |
| **C2** | **表面与材质** | ① 阳极氧化铝：GGX 粗糙度 0.28–0.38 各向同性 + 亚像素级喷砂微法线（相关长度 0.5–5 µm 等效）② 屏幕玻璃：Fresnel 反射 + 介质透射 + 屏幕自发光，反射率随入射角变化符合 Schlick ③ 键帽 PBT 微磨砂 + 双曲面 ④ **材质一致性**：同一零件不混亮/哑面（logo 镜面除外）⑤ 与参考图同区域亮度梯度误差 ≤ 5%（p10–p90） |
| **C3** | **光学与光照** | ① 影棚软箱倒影位置/形状与参考一致（2 主光 + 1 轮廓光）② 接触阴影：笔触宽 ≤ 3 mm，无硬边 ③ 无 CG 破绽：无完美直边锯齿、无 banding、无死黑/死白 ④ 曝光/白平衡与参考图同基准（灰卡对齐）⑤ 景深 + 轻微镜头像差（CA ≤ 1 px、暗角、传感器噪声）|
| **C4** | **细节与语义** | ① 78 键 ANSI + 12 全高功能键 + Touch ID，空格键中心 = 键盘中心（±0.05 mm）② 键距 19.05/18.5 mm 全域 ±0.1 mm ③ 刘海 40×6 mm + 摄像头孔 + 屏下「MacBook Pro」字样 ④ 接口：MagSafe 10.5 / USB-C 8.27 / HDMI 14.98 / SDXC 27.21 / 3.5mm Ø3.44 mm，同一水平中线 ⑤ 脚垫 4×Ø15 mm 距边 22 mm；底盖铭牌 ≈79×14 mm 三行 ⑥ logo 37.1×45.6 mm 上偏 4.1 mm 镜面嵌件齐平 |
| **C5** | **屏幕内容** | ① 真实 macOS 桌面语义（菜单栏/刘海避让/Dock/窗口/壁纸）② 正确的色彩管理（Display P3 → sRGB 变换）③ 亚像素级抗锯齿 + 背光渐晕 ④ 亮度与环境反射叠加物理正确（屏幕不「糊」在玻璃上）|
| **C6** | **渲染质量** | ① 长边 ≥ **1600 px**，16 bit 内部 → 8 bit 输出带抖动 ② 降噪后平坦区噪声 σ ≤ **1.0/255** ③ 边缘覆盖率抗锯齿（无阶梯）④ 无 firefly（亮度离群点 ≤ 1e-5 像素比例）⑤ 色调映射（AgX/ACES 拟合）无通道截断 |
| **C7** | **盲测辨识** | 独立模型 6v6 A/B 去标识盲测，误判率 ≥ **40%**（随机水平 50%；<40% 视为「一眼 CG」）。≥ 50% 即满分 |

## 自评流程

每轮：
1. 跑全部可测项（脚本化，落 `iteration-records/`）
2. 按 7 类打分，找**最低分项** = 当前最弱一环
3. 只改最弱一环，做到该类的极限
4. 重测；若某类分数下降 → 回退

## 不可让步的红线

- 零依赖：不引入任何第三方库；解码/编码/渲染/几何全部自实现（系统字体文件除外，属系统资产）
- 门禁全绿 ≠ 像：结构合法性与设计保真分开报告
- 不允许宣称完成除非 C7 达标
