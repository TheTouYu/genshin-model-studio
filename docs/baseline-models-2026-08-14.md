## 能力结论（两个模型共性）

1. **能力合格**：给接口知识 + 数据核验闭环，两个模型都能独立设计并完成结构正确的风扇（外环/辐条/电机/三叶 120°/支架/底座贴地/无悬空），且都能自我纠错（API 数据抓到错误 → 重画/修正）。
2. **探针式学习是主要成本**：都花 2 轮先画测试件摸服务端语义（y 归一化、lift、axis、loop 闭合阈值、height 抬升语义、loop 实体形状限制），再正式画。
3. **知识缺口（断言外不做）**：
   - 叶片桨距角/立体扭转：0/2 主动做
   - 部件间隙/不重叠：0/2（gpt 叶片-电机重叠 4.4cm 且自认通过——断言 7 只查 y 链条，未查径向重叠）
   - 前后层次（环-叶-电机-后罩 z 分层）：0/2
   - 主动配色：1/2（gpt 用三色渐变叶片 + 分部件配色）
4. **共同错误模式**（画法铁律文档应覆盖）：
   - loop 闭合阈值（首尾 < 包围盒对角线 20%）：2/2 踩
   - rod height 是 y 抬升不是 z 厚度：1/2 探针发现（与 lathe 铁律 #2 一致）
   - rotate 索引漂移：1/2（ds 把第 4 根辐条复制成叶片，6 辐条+1 叶，数据核验抓到）
   - 形状识别限制（loop 椭圆/矩形实体 → 400 或 10009001 盒体）：2/2 探到，都用 circle 规避
5. **效率画像**：单次 12-15 分钟 / $0.05-0.24 / 3-4 轮。其中 ~2 轮是探针——这些语义已在画法铁律文档（docs/drawing-rules.md）中，模型得读后应能压到 1-2 轮。

## 基线暴露的断言设计缺陷（下次基线修正）

- 桨距角/间隙/层次未进断言 → 模型不主动做。基线 v2 断言应包含：叶片 rotation 带桨距（非 [90,0,0]/[90,0,120] 纯平盘）、叶片与电机径向不重叠（内缘 > 电机半径）、存在 ≥2 个 z 平面（层次）。
- 形状类别断言（全部 10009008）逼模型放弃 loop 椭圆（400/盒体）——这是工具限制，不是模型缺陷；如要测 loop 用法需改服务端支持或放宽断言。
