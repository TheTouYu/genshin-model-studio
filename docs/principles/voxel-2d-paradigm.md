# 《压缩三维为二维》论文范式提炼与项目对应

> 来源：`voxel-3d-to-2d/`（实证论文仓库，26 次真实 DeepSeek API 调用 + 确定性校验器 + 原始响应存档）。
> 本文是阶段 0 交付：论文范式、五类任务设计、确定性校验器清单、失败模式清单，以及与本项目的对应关系。
> 后续 ADR（0003）与基准体系（benchmark/）以此文档为锚点。

## 1. 论文核心结论（分析的锚点）

1. **精确规格下，三种表示（3D 坐标 / Y 层 2D 切片 / 正交三视图）全部满分**（IoU=1.000 × 18 次）——表示方式不是精确任务的瓶颈；模型在 effort=max 下具备可靠的"规格执行"能力。
2. **自由生成下，逐层 2D 切片显著优于直接 3D 坐标**——后者系统性产生"壳"式缺陷：环形地板（室内地板实心率 0.00 vs 1.00）、悬空屋顶、门高不足（1 格）、漏窗。
3. **正交三视图是好"图纸"但不是好"状态"**：三张投影一般不能唯一确定体素结构（离散断层成像，Ryser/Gardner）；自由生成时跨视图一致性不可靠（0 违规 vs 24 违规）。
4. **工程范式**："二维是模型的推理画布，三维一致性交给确定性代数兜底"——逐层切片为世界状态，模型只做 2D 层编辑，堆叠/投影/重力/一致性由代码完成，生成后跑不变量校验并自动修复（补内部地板、补门高、补支撑）。
5. **列式物理（重力）是 2D 压缩的理想形态**：按 (x,z) 列分解成独立 1D 问题，两种表示均精确。
6. **方法学**：小样本（n=2~3）结论是方向性的，关键条件要重复；网格评分含方向翻转容错（行翻/列翻取最优，不算加分）；评分器缺陷要发现即修，修正后全量离线重算（原始输出存档）；"悬空块"等指标要警惕误报（Minecraft 石材合法悬空），以语义特征为准。

## 2. 五类任务设计（论文 → 本项目映射）

| ID | 论文任务 | 论文校验方式 | 本项目映射（benchmark/tasks/Tn） | 本项目校验方式 |
|---|---|---|---|---|
| T1 | 精确规格小屋（80 块，逐条规格） | 逐格 IoU + 结构特征分（地板/围墙/屋顶/门洞/空心各 20%） | 精确规格石亭（6 个官方元件，逐条规格） | 元件级 IoU（规范化后贪心匹配）+ 特征命中分解 |
| T2 | 坐标旋转变换 (x,y,z)→(7−z,y,x) | 变换公式逐点核对（IoU） | 给定结构 → 绕 Y 旋转 90° + 平移（公式给定） | 对 GT 施加同一变换后逐元件核对 |
| T3 | 螺旋楼梯塔（127 块，不给出总数） | 规则/模式一致性（台阶序列检查） | 拱桥（桥面 N 块等宽板 + N 根立柱，N 由总长/板宽推导，不直接给出） | 模式一致性：均匀步长、等高、等宽、支撑、无缺口、无多余 |
| T4 | 自由生成乡村小屋（只给功能要求） | 结构不变量（地板实心率/支撑/连通/特征齐全） | 自由生成四腿桌（只给功能要求：桌面/四腿/贴地/净空/对称/比例） | 结构不变量：贴地/支撑/净空/对称/比例/无穿模 |
| T5 | 重力物理（10 沙块下落） | 按 (x,z) 列分解重堆叠比对 | 箱体重力（4 个给定初始位置的箱体，含悬空，计算下落后的最终结构） | 确定性重力求解器（中心点支撑）+ 逐元件比对 |

设计原则（沿用论文方法学）：
- T1/T2/T5 有真值（GT 由校验器代码确定性生成，不落盘给会话可见）；T3 有可推导的规则真值；T4 无真值，用不变量评分。
- 网格/布局类比较含方向容错：本项目为连续坐标域，方向容错体现为**元件规范化**（盒体绕 Y 的 k×90° 旋转等价于交换 scale.x/z，归一化后不计为错误——对应论文"行翻/列翻取最优，不算加分"）。
- T4 每条件跑 2 次取均值；其余 1 次。小样本结论为方向性，靠多轮重复与趋势表增强可信度。

## 3. 确定性校验器清单（全部纯确定性、与模型无关、可离线重算）

| 校验器 | 用途 | 说明 |
|---|---|---|
| 解析器 | 所有任务 | 从模型输出文本提取 structure.json 超集（去代码块、花括号配平）；解析失败 parse_ok=false、记 0 分 |
| 元件规范化 | T1/T2/T5 | 浮点吸附（1e-3）、盒体绕 Y 90° 旋转规范化（scale 轴交换）、圆柱绕 Y 旋转不可见规范化 |
| 元件贪心匹配 + IoU | T1/T2/T5 | GT 与预测按规范化键排序后贪心匹配（resourceId 必须一致，位置/尺寸容差内）；IoU = 匹配数/并集数 |
| 变换核对 | T2 | 对 GT 施加提示词给定变换（Ry(90°)·p + t），逐元件与预测比对 |
| 模式一致性 | T3 | 步长均匀（高度/深度/宽度方差）、支撑（下一块贴上一块顶面）、无缺口（区间首尾相接）、无多余元件 |
| 结构不变量 | T4 | 贴地（底 y∈[−ε,ε]）、支撑（四角区各有腿且腿顶贴桌面底）、净空（桌面底 ≥ 0.5m）、对称（腿对桌面中心镜像）、比例（腿不超出桌面外缘）、无穿模 |
| 重力求解器 | T5 | 按"中心点支撑"规则确定性求解下落位置（迭代至稳定），与预测比对 |
| 投影一致性 | 备用（未入选基准任务） | 论文 C 条件三视图存在性检查；本项目 2D 画布三视图投影一致性可在产品侧复用 |

## 4. 失败模式清单（论文实证 + 本项目推断）

| 模式 | 论文证据 | 本项目对应 | 捕获手段 |
|---|---|---|---|
| 壳式缺陷（环地板/悬空屋顶/门高不足/漏窗） | FF-A1/A2 | T4 缺腿/腿不贴地/桌面下净空不足/漏对称 | T4 不变量校验 + 修复管线补支撑 |
| 规则丢失（台阶序列错位/缺层） | 楼梯塔（修复前评分器漏检 2 格） | T3 步长不均匀/缺块/间隙 | T3 模式一致性逐项核对 |
| 跨视图违规（三视图不一致） | FF-C2 24 处违规 | 本项目无真 3D 画布（ADR-0002），三视图仅为派生投影 → 投影一致性校验为产品侧防御 | 产品侧投影一致性校验（提案 a） |
| 坐标遗漏/重复/越界 | 解析器过严/格式漂移 | 输出 item 数不符、位置越界（y<0） | 解析器 fail-closed + 越界检查 |
| 方向约定错误（行/列/轴向写反） | 论文网格评分含翻转容错 | 盒体 scale 轴序写反、旋转方向写反 | 元件规范化（90° 旋转等价类） |
| 方向翻转误当能力 | 论文明确"取最优，不算加分" | 规范化不计为加分 | 评分注释中显式记录规范化 |

## 5. 工程范式（论文 §6.1）→ 本项目落点

> **体素世界状态以逐层切片存储，模型只做 2D 层编辑；堆叠、投影、重力、碰撞与一致性检查全部由确定性代码完成；自由生成后运行不变量校验，自动修复典型缺陷。**

| 论文范式要素 | 本项目对应（详见 ADR-0003） |
|---|---|
| 世界状态表（逐层切片）唯一，视图是派生投影 | 三维数据（structure.json items）是唯一状态表；前/俯/侧视图只是派生投影（ADR-0002 已定 2D 画布 + 投影）；新增投影一致性校验 |
| 生成后不变量校验 + 自动修复 | 新增确定性校验/修复管线（贴地吸附、支撑修复、规范化），作为候选版本组件进入 A/B 基准，成熟后落地 API |
| 模型只做 2D 层编辑 | 提示词协议 v2 起：分层 2D 推理协议——先规划每层 XZ 平面布局，逐层堆叠，层间衔接由"下层顶=上层底"的代数规则保证 |
| 精确规格 vs 自由生成双模式 | 任务提示词分两类：T1/T2/T3/T5 精确规格，T4 纯功能要求；协议提供对应回退策略（见 ADR-0003 提案 c） |
| 列式分解降低推理负担 | 可分解运算（重力/堆叠/支撑检查）按轴列式分解，模型只需逐列/逐层推理（T5 即此形态；产品侧生成器可复用） |
| 方法学：重复、方向容错、全量重算 | 基准体系：T4 ×2 取均值；元件规范化容错；任务冻结 hash、勘误流程、rescore 离线重算 |

## 6. 项目现状核对（与本范式相关的既有资产）

- 数据契约：`src/core/structure.ts`（fail-closed 解析）、`src/core/encoder.ts`（.gil 编码）、`readback.ts`（回读）——**状态表已存在**。
- 画布：2D canvas + 前/俯/侧视图投影（ADR-0001/0002）——**视图已派生化**，但无"投影一致性校验"。
- 生成：`src/draw/generate.ts`（笔画 → 元件）——生成器语义上已是"确定性代数兜底"，但**无生成后不变量校验/修复**。
- 测试：tests/ 29 条 golden 测试（npm test 全绿是硬约束）。
- 缺口：a) 投影一致性校验缺失；b) 生成后校验/修复管线缺失；c) AI 技能/API 的提示词协议无"精确规格 vs 自由生成"双模式设计；d) 几何/物理运算未按轴/按视图列式分解表达。
