# 高精度建模核心方法（以足球运动员 300 面档为例，2026-09-05）

> 适用：genshin-model-studio 画线建模（基础元件拼装）从「能看」升级到「游戏可用精度」。
> 本波实证：v3 足球运动员（295 元件 / 114 笔画 / count=60 / 球缝环≈182 段）。

---

## 核心方法（七步）

### 1. 先定预算，再分配面数
- 用户/任务的「面/元件数」预算是第一约束（本次约 300 面）。
- 预算大头给「看得见的精度」：球缝环等高精度环 182 段；其余 113 件做细节。
- 不要无脑把 count 拉满：`count` 是**每个细分轮廓的段数**，直线段始终 1 件（有专门优化），
  只有圆/椭圆环才会放大为 `3×(count+1)` 段——这是本工具的高精度主杠杆。

### 2. 用参数控制精度，而非堆重复件
- `count`（UI 数量滑块）驱动环精度：`count=60 → 球缝环 3×61≈183 段`，视觉上是平滑环线。
- 环默认 `spec.seg=48` 只是原始点密度，最终段数由 `closed&&keepClosedDetail ? max(rdp, 3×(count+1))` 决定。
- 所有环共享 count：想单独控制某环，需要按笔画粒度升级（当前 API 无 per-stroke count，先按全局取）。

### 3. 分层设计：轮廓 → 贴附 → 装饰
| 层 | 作用 | 选材 |
|---|---|---|
| 轮廓层 | 决定可读剪影（头/躯干/四肢/球/鞋） | sphere（头/球）、el-disc（躯干/短裤/靴底）、rod（四肢） |
| 贴附层 | 加在轮廓上的色带/面板 | disc axis up（腰头/袜口/护膝）、disc axis front（徽章/五官/球拼块）、ring（球缝环） |
| 装饰层 | 小件烟火气（鞋带/鞋钉/发丝/缝线/雀斑） | 细 rod（0.0028~0.006）、小 disc（r 0.005~0.02） |

**每条细节都必须回答「它让哪里更好读」**；答不出就删（本次删掉了胸前/背后条纹与袖口竖条——
近景下它们和号码叠在一起变成“哑铃”，删除后立即清晰）。

### 4. 面向“基础元件库”选材，不做网格
- 硬约束：无任意三角面片/布尔；连续曲面靠离散段组合。
- 选材速查：圆滑体积→`sphere`/`cylinder`；片状/盘→`disc`/`el-disc`；线→`rod`；环→`ring`；
  平面→`plate`；弧线罩→`arc`。
- 球体是 2026-09-05 新增的基础元件覆盖（`gms.part('sphere')` / `opts.resourceId=10009002`），
  头/足球用它后 QA 明显提升。

### 5. 物理正确与角色分离
- 结构件（承重/连接）→ 命名 + `gms.link` + `gms.verify()`（本次 20 条 link 全 contact，floating/collides 空）。
- 装饰件 → 不命名（不参与 collides 检查），视觉贴附即可，避免误报。
- 命名/连接是“结构性事实”，必须是**声明出来的**，不是坐标心算。

### 6. 标定与持久化铁律
- `options.canvasWidthPx + canvasHeightPx` 是像素↔世界的固定原点；**任何重建 options 的路径必须保留**。
- 作品保存后必须验证：刷新主页面 + 独立预览 `preview-demo.html`，两者都要组装（本波曾因丢
  canvasWidthPx 触发「身体解散」，已修复并写入技能坑 #17）。

### 7. 视觉迭代闭环
- 顺序：先轮廓（5 视角截图通过）→ 逐层加贴附/装饰 → 每轮对比截图。
- 检查项：遮挡/悬空/缝隙、装饰与主题的可读性、色彩层次（红球衣/深蓝短裤/白袜/黑靴 + 白球黑块）。
- 收敛信号：近景不再有“看不懂的凸起/线头”，五视角无新缺陷。

## 本波数据（可复现的预算参考）

- 114 笔画 / **295 元件**（目标 300±20，达成）
- count=60：球缝环 ≈ 182 段（10009008），其余 113 件 = 身体细节 + 球拼块/缝线
- 元件构成：10009002 球体 ×3（头/头发/足球）、10009008 圆柱/盘/杆 ×292；无地面/背景（聚焦球员+球）
- 细节清单：鞋底/鞋面/鞋带×2/鞋钉、袜口/袜条/踝带/护膝/护胫、短裤腰头/侧条/裤脚、
  领口/白徽/前后号码10/下摆、腕带/手套、耳/侧发/28 根刘海/眉/鼻/嘴/发带/雀斑、
  球缝环/10 黑色拼块/6 缝线
- 物理：20 条 link 全 contact，floating=[], collides=[]；`gms.verify() ok=true`

## 一句话总结
**先定预算，把最高段数给最值得细分的曲环；用「轮廓—贴附—装饰」三层组织细节，
每条细节都要有可读性；结构件声明连接、装饰件只管视觉；每次增量都截图对比，五视角+刷新闭环才算完成。**

## 补充：人物/角色精准还原（2026-09-05 甘雨足球服 v4 实证）

1. **先列特征表，再分配预算**：头发大体积（球体 + 蓬松马尾）、角（poly 曲线 + cone 尖）、
   发型（刘海/侧发/呆毛）、服装标志（号码/背字/腰条/鸢尾纹）、鞋/手套。每条特征写明颜色与参考位置。
2. **发丝用 `gms.part('poly')`**：世界坐标 3D 折线，N 点 → N-1 根杆；有 z 时不重采样，
   密度由点数直接控制——「一根发束」= 1 笔画，比逐根 rod 省笔画且可做波浪/摆尾。
3. **收尖/锥形件用 `gms.part('cone')`**（10009009）：角尖、发尾、鞋钉等；曲线主体用 `poly` 或 `arc`。
4. **重复件用循环 + 确定性伪随机**：发束按角度均分 + 微扰，保证可复现且密度均匀。
5. **配色对照参考图给 hex**，每层细节（发/肤色/白球衣/蓝纹/黑手套）都要有明确色值。
6. **侧/背视角必须单独截图**（`setCamera({yaw:Math.PI,...})` 加拍 back）：马尾、背字、
   角在正面可能被遮挡，三视图都要复现。
7. **与共享浏览器隔离**：多人/多任务时用独立 Edge 实例（新 `user-data-dir` + 新调试端口 +
   独立 `BU_CDP_WS`），避免共享窗口互相覆盖 localStorage / 作品状态（本波实测共享窗口会
   间歇性清空/叠加笔画，隔离实例一次跑通）。

甘雨 v4 实证：218 笔画 / **511 件**（≤3000），count=60；`poly` 70 束马尾 + 26 刘海 + 8×2 侧发，
`cone` 2 角尖；6 视角 + 背视截图复核。
