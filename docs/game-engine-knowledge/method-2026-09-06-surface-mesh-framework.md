# 表面网格重建框架（framework-first）——甘雨三视图精准还原方法论

> 2026-09-06，用户核心指导：
> 1. 真正的模型是**由很多“面”拼起来的连续表面**——把人物曲线拆成许多小面；
> 2. **框架必须正确**：几千个面就能精美还原；精度只是参数（调密度可到上万装饰物）；不能停在几百件。

---

## 1. 建模最大问题（先想清楚）

- **旧范式错在“以部件为单位”**：棒（rod）+ 球（sphere）+ 盘（disc）拼布娃娃。
  视线是“一根手臂 = 一根圆柱”，不是“手臂表面由一圈圈小面组成”。
- **与三视图的真实差距**：
  | 参考图（真模型） | 旧做法（v4 及以前） |
  |---|---|
  | 身体是连续贴合的曲面（腰/胸/髋曲线） | 圆柱/椭盘堆叠，轮廓是“管子+碟子” |
  | 发丝是沿头皮垂下的**面片带** | 细杆捆成一束，像扫帚 |
  | 衣物是贴合身体的**表面面板** | 光杆上贴小盘装饰 |
  | 角/饰边是**曲面件** | 折线段/圆锥近似 |
- **设计思路差异**：真实建模者以「**曲线 → 面**」为单元（截面环放样、蒙皮、飘带），
  而不是以「基础元件 → 摆件」为单元。先有**面的生成算法**，再谈用什么基础元件。

## 2. v6 框架（已验证正确）

| 层 | 算法 | 基础元件 | 说明 |
|---|---|---|---|
| 身体/四肢 | **loft（截面环放样）**：每个高度一个椭圆截面环，相邻环逐段生成四边面板 | 平面 `quad`(10009003) | 女性曲线 = 环的 rx/ry/cx/cz 随高度变化（腰细、髋宽、小腿收） |
| 头发 | **ribbon（飘带面）**：沿流线点列生成连续窄面板，宽度渐变 | `quad` 窄面板 | 刘海/侧发/马尾各几十条曲线 × 多段小面 |
| 角/饰边 | 飘带 + 三棱锥面/锥 | `tri`(10009006)/`cone`(10009009) | 角曲线、鞋楔、菱形饰 |
| 五官/标志 | 小面/杆/盘点缀 | 10009008/10009003 | 眼/眉/口、GANYU/10 |
| 密度 | `D` 倍率（环数×段数×发丝数） | — | D=1 ≈ 1339 面；D 增大 → 几千~上万 |

**面板朝向算法（关键，已单面板校准）**：
`quad(center, normal, w, h)` 用法线 n（XZ 面内）→ 旋转 `[90, 90°−θ, 0]`（θ=atan2(nz,nx)）——
平面元件零旋转变平（法线 +Y），Rx(90) 立起、Ry 绕 Y 转到目标法线；实测面板与表面贴合。
（早期用通用基→欧拉在小角度退化（α=±90）时选错解，面板成“纸屑”；单面板实验修复。）

## 6. v7 进展（曲线网络 + 衣物独立壳，2026-09-06）

- **surface(rings, u)**：截面环 → UV 曲面格；法线取 `cross(dU,dV)`（含坡度），逐格小面。
- **quad 法线公式推广**：`rot=[90+δ, 90°−θ, 0]`，δ=−asin(ny)、θ=atan2(nz,nx)——任意坡度面板贴合（单面板校准 + v7 表面格实测）。
- **衣物独立壳**：`offsetRings(rings, d)` 把身体表面外扩 d（间隙）生成**独立壳层面**——
  球衣/短裤/袜/袖各自是独立面，与皮肤底座分层（用户指出的核心难点：衣服是另一个面）。
- v7 实测：**1622 面**（10009003 面板 ×1596 + 圆柱 21 + 球 1 + 锥 2 + 三棱锥 2）；
  正/侧/背视角均无纸屑、无穿模，蓝白球衣/蓝腰条/白短裤/白袜/肤色四肢/蓝发双角成立。
- 密度参数化：U（绕周曲线数）与环数为精度旋钮；框架固定后调 U 即可几千→上万面。

**下一步细节纠正**：① 身体曲线（胸/腰/髋/臀/小腿肚）加环描形；② 发壳完整包覆+长马尾加粗；
③ 上衣/短裤**开口边**（领口/袖口/下摆/裤脚）与身体之间的间隙与厚度；④ GANYU 10 等贴面图案；
⑤ U 1→2 密度验证平滑度。

## 7. 测量驱动：从三视图原图提曲线（不靠记忆，2026-09-06）

流程（脚本 `scripts/extract-ganyu-profile.py`）：
1. **保存原图**：`reference/ganyu-3view.png`（用户 Downloads 原件 1254×1254）。
2. **切三视图**：按前景列分布自动切成 `ganyu-{front,side,back}.png`（各 ~387/232/385×1125）。
3. **逐行剪影**：前景=与边缘均值灰差异>40；每归一化高度 h 输出 `w`(全宽)、`bodyW`(含身体中轴的主段宽)、
   `minX/maxX`、颜色分带占比（white/hair/skin/blue/red/dark）。
4. **中轴+平滑**：轴=脚/腿行中点中位数；身体宽=含轴主段（避开张开双臂/马尾）；5 点中值平滑。
5. **测量环** `reference/ganyu-rings.json`：front 宽×side 深 → 世界截面环（y=0.46..0.94，H_M=1.18m）——
   v8 建模脚本将直接读这套环（躯干/胸/腰/髋曲线），不再手拍尺寸。
6. **人工复核**：`ganyu-front-overlay.png` 红色横线覆盖全身剪影（已 read_image 复核，分段正确）。

已知待改进：腰线行 bodyW 因双臂紧贴躯干略窄 → 用颜色分带（white/blue 中心区 vs 手臂 skin）进一步剥离。
