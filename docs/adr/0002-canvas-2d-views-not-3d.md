# 画布保持 2D，加视图投影（不做真 3D 画布）

考虑过把画布做成真 3D（在任意视角下画线），但画线交互本质是 2D 的——鼠标永远落在"当前视图平面"上；真 3D 画布要处理深度与画线平面选择，实现复杂且反直觉。

决策：画布保持 2D canvas，数据已 3D 化（见 ADR-0001），画布带视图状态（front=XY / top=XZ / side=YZ 投影平面）。画线 = 2D 坐标按当前视图反投影成 3D 点；显示 = 所有笔画按当前视图投影回画布——画布所见即 3D 模型的当前视角投影，与预览天然一致。选中笔画后的整体移动/旋转在 2D canvas 上以矩阵运算实现（拖拽 = 视图平面内移动，旋转手柄 = 绕视图法线转）。

阶段 2 落地视图切换，阶段 3 落地选中交互；阶段 1（ADR-0001）只做数据与生成层，画布暂保持正视图。
