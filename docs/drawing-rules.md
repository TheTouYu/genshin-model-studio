# 画法铁律（模型建模必读 · v1）

> 用途：任何模型在 gms 上建模前必须读本文档。它把"代码能表达"变成"模型表达得对"。
> 版本：v1.2（2026-08-14）——v1.1 模型反哺（椭圆长宽比/半径直径/bbox.m）；v1.2 组件化章节（gms.part）。
> 来源：phase2/4/5 PRD、postmortem 2026-08-12/13、十二期视觉核验闭环、双模型基线。

## 0. 分层（先对齐再动手）

1. 核验层：截图 + inspect-draw-model.sh 数据核验 + 视觉模型代理——只读"模型长什么样"，与建模代码无关
2. 代码层：window.gms 命令层——"能表达"；本文档负责"表达得对"
3. 模型层：模型学会用代码建模——本文档是模型层的教材

## 1. 建模前必读（通用铁律）

| # | 铁律 | 原因/坑（含基线实测） |
|---|---|---|
| G1 | 先 gms.summary() 读 calibration（默认 320px=1m），一切米尺寸 = 像素/320 | 不读标定就不知道模型实际多大 |
| G2 | solid（柱体）轮廓必须封闭；loop 首尾距离必须 < 包围盒对角线 20%（首尾重合最稳） | 否则 400"柱体渲染需要封闭轮廓"/"loop 参数非法"——双模型基线都踩过 |
| G3 | 画布 y 向下为正；笔画总 bbox 底 ≈ 世界 y=0（地面）。贴地件（底座）画到 bbox 底 | 实心件默认贴 y=0；画歪即悬空 |

| G9 | 每个部件用 gms 命令后立即 summary() 自检（参数/bbox/元件数），不攒一批 | 错误早发现，迭代轮数从 3-5 压到 1-2 |
| G10 | 画完用 scripts/inspect-draw-model.sh 取服务端 items 做断言核验，再截图 | 人眼/ASCII 猜不可靠；数据以服务端为准 |
| G11 | rod 的 height 是"抬升"语义（position.y += height），不是厚度！想定高就把画布像素画对 | 基线 gpt 探针实测：height:0.34 表现为 y 抬升；与 lathe 铁律 #2 一致 |
| G12 | loop 实体（solid）有形状限制：椭圆/矩形可能 400 或生成 10009001 盒体——确认支持的轮廓用 circle | 双模型基线都探到，改用 circle 规避 |
| G13 | 立体感三件套：叶片桨距角（绕长轴扭转 10-15°）、前后层次（z 分层：叶片/环/电机/后罩各一平面）、分部件配色 | 基线 0/2 模型主动做；断言外不做是模型常态，目标要有断言驱动 |
| G14 | rotate/delete/props 前先 gms.list() 核对索引（每笔 {index, points, closed, render, center}）；summary 的 render/height/axis 是归一化有效值 | 基线复盘 2b：ds 索引错位致 6 辐条+1 叶全量重画；gpt 索性规避 rotate |

## 2. 风扇画法（十二期实测定版）

结构：外环(48 点 loop, 杆) + 辐条×4(rotate 4, 杆) + 电机(solid front) + 后罩(solid front) + 叶片×3(loop 椭圆, solid front, rotate 3) + 支架(杆) + 底座(loop 椭圆, solid)

- 中心 (302,250) @320px=1m；外环半径 80px=0.25m（直径 0.5m）；电机半径 14px=0.04375m（直径 0.0875m）；后罩半径 20px=0.0625m（直径 0.125m）；叶片 40×28px 椭圆（长宽比 1.43:1）、厚 0.002m
- **椭圆长宽比上限（ds v2 实测）**：4:1 拒收（400 暂不支持该轮廓），2:1（底座 64×32）与 1.43:1（叶片）安全；底座用 64×32px、圆心 y=367（bbox 底 383 接地）
- **同面**：外环/辐条/支架 transform.position z=-0.04（叶片 z=0 之后、电机 z=-0.045 之前）
- **叶片桨距角 12°**：源 transform.rotation=[102,0,0]（绕长轴=世界 X）；副本由四元数继承，勿手写欧拉
- 抬升：LIFT_M = (bbox底 − 中心y)/320 ≈ 0.416；电机 lift=0.3756、叶片 lift=0.4146
- **bbox.m 是 原始px/320 的显示值，不是归一化坐标**：底座底画在 383px（越出 320px 画布允许），服务端归一化后世界 y=0.4156 与 summary 的 bbox.m（minY≈0.53）不一致——核验以 inspect 输出为准
- 笔画顺序（铁律 G7 锚点）：0 环 / 1 辐条 / 5 电机 / 6 后罩 / 7 叶片 / 10 支架 / 11 底座；rotate(1,…,4) 与 rotate(7,…,3)
- 验收断言：外环/辐条/支架 z 一致；叶片 3×scale[1]≈0.002 且 120° 对称、rotation 带桨距（源 [102,0,0]）；叶片内缘 > 电机半径+5mm；后罩 z=-0.085 贴电机；底座 y∈[0,0.01]；无悬空


## 2.5 组件化画法（gms.part，基线 v3）——声明组件，不做几何推导

每个组件 = 一行 `gms.part(type, spec)`，参数全用**米制世界坐标**：
- `x`：左右（0 = 模型中心）；`y`：高度（0 = 地面）；`z`：前后（0 = 叶片平面，负 = 向后）
- 内部自动完成：px 换算（320px=1m）、solid 自动 lift（y − 厚/2）、显式闭合点、颜色归一化
- **约束**：先画贴地件（底座 y=厚/2）稳定 bbox 底，再画其余（世界 y 以当前 bbox 底为基准）

| 类型 | 参数 | 说明 |
|---|---|---|
| `disc` | x, y, z, r(半径), thick(厚), axis(up/front/side), color, rotation? | 圆盘柱体（底座/电机） |
| `el-disc` | x, y, z, rx, ry, thick, axis, rotation?, color | 椭圆盘（叶片；长宽比 ≤2:1，4:1 会被拒） |
| `ring` | x, y, z, r, seg?(默认 48), color | 杆环（防护罩；48 段起步防多边形） |
| `rod` | x1,y1 → x2,y2（米），z, color | 杆（辐条/支架） |

风扇组件表（十三期定版——叶片防交错参数来自 v3-gpt 实测验证 + 补前护罩；逐行执行即得成品）：

```js
gms.part('disc',    {x:0, y:0.006,  z:-0.04, r:0.1,    thick:0.012, color:'#3f4650'})   // 底座（先画，定 bbox 底）
gms.part('rod',     {x1:0, y1:0.416, z:-0.04, x2:0, y2:0.01,               color:'#5b6270'})  // 支架（电机中心→底座）
gms.part('ring',    {x:0, y:0.416,  z:-0.04, r:0.25,                     color:'#aab4c0'})   // 外环（与支架同面）
gms.part('rod',     {x1:0, y1:0.416, z:-0.04, x2:0.25, y2:0.416,          color:'#9aa6b2'})  // 辐条源 → gms.rotate(3, 0.416→px? 用 list 核对后 rotate(3, cx, cy, 4)
gms.part('disc',    {x:0, y:0.416,  z:-0.045, r:0.04375, thick:0.08, axis:'front', color:'#4a4f57'})  // 电机
gms.part('disc',    {x:0, y:0.416,  z:-0.085, r:0.0625, thick:0.015, axis:'front', color:'#6b7280'})  // 后罩（贴电机后表面）
gms.part('el-disc', {x:0, y:0.416,  z:0, rx:0.125, ry:0.0875, thick:0.002, axis:'front', rotation:[102,0,0], color:'#e8c15a'})  // 叶片源（桨距 12°）→ gms.rotate(?, 中心, 3)
```

**v4 接口（gpt 视觉自审反馈落地）**：
- gms.rotatem(i, x_m, y_m, n)：旋转中心用米制世界坐标（x 相对中心、y 相对地面），内部换算——不必再算画布像素
- gms.rotate(i, cx, cy, n) 返回带 rotated: {srcIndex, srcId, copies:[{index, id}]}——复制后直接知道副本索引/id，无需 list() 反推
- gms.delete(id) / gms.props(id, ...) / gms.rotate(id, ...)：索引与 id 都可用（id 稳定，插入/删除不漂移；id 用 gms.list() 查）
- **G15 漂移警告**：偏置组件（x≠0 的非对称件）画完必须 inspect 核对实际 position，漂移则 delete(id) 重画校正

## 3. 水杯画法（lathe 模式，2026-08-12 实测定版）

铁律：杯身用母线折线车削（10009012 开口薄壁），绝不用 circle+solid（那是实心柱）；把手必须 render:'rod'（否则被车削成小圆筒）；把手 y 控制点必须在杯身高度内；杯底 solid 圆心 x 必须与母线轴 x 相同；母线/把手 height 是抬升语义不是高度

## 4. 核验闭环（每轮必走）

1. 画完 → gms.summary() 自检（drawStatus 格式 ✓ N 笔 · M 封闭 · K 元件）
2. scripts/inspect-draw-model.sh 取 items → 逐条断言（输出含 perStroke 映射：每笔 itemCount + 样本，无需几何反推）
3. capture-views.sh 截 iso/top/front/left/back/closeup 六视角
4. 视觉模型（gpt-5.6-sol）独立核验：审美+实现双角度，坐标化缺陷
5. 缺陷 → 修复 → 重跑 2-4（数据核验全过 + 视觉通过才算完成）

## 5. 基线错误模式（2026-08-14 双模型实测，防再踩）

| 错误 | 现象 | 规避（对应铁律） |
|---|---|---|
| loop 闭合失败 | 首尾 >20% 对角线 → 中文 Error | G2 |
| height 语义误用 | rod height 当厚度 → 实际 y 抬升 | G11 |
| rotate 索引漂移 | 复制错笔画（6 辐条+1 叶） | G7 + G9 即时 summary |
| 实体形状限制 | loop 椭圆/矩形 → 400 或 10009001 盒体 | G12 |
| 断言外不主动 | 无桨距/无间隙/无层次 | G13 + 断言驱动 |
| 径向重叠 | 叶片内缘插入电机 | G6（断言补径向间隙） |

## 6. 网格-面片体系铁律（mesh route · G18 起）

> 适用于「网格-面片 route」建模（自定义多边形 / 有机曲面）。与 §1 的 G1–G17 是两套并行规则：§1 管经典画线（stroke），本节管面板化 / 门禁 / 放样。阈值与 `src/mesh/panelize.ts`、`src/mesh/verify.ts` 默认值逐字一致。

| # | 铁律 | 原因/坑（含实测） |
|---|---|---|
| G18 | **面片必须带显式局部基**（宽度/法线/深度三轴），旋转由局部基 → YXZ 欧拉；绝不用「法线 + 猜测上向量」 | 只有法线的面片在弯曲环面上会「滚转/翻面」（设计文档 §2.2）；quadB 已用显式局部基解决，新体系强制继承。反例：给弯曲曲面只传 normal 不传局部基 → 面片绕法线乱转，出现缝隙/滚转 |
| G19 | **要水密必须 cap:'both'**；cap none 是开放管面，门禁报开边 | 开边 = 每条边只被 1 个三角引用；放样默认 no cap，门禁 watertight 如实失败。反例：做水密杯/脚只 loft 不封盖 → verify 报「水密性未通过：开边 N 条」 |
| G20 | **门禁 FAIL 不出件**；`--no-gate` 仅用于演示/诊断，产物标 `SKIPPED_GATE` | 门禁失败拒绝导出 `.structure/.gil/.gia`（只写 `.summary.json` 诊断）——这是保住质量的出口。反例：`--no-gate --force` 强出件 → 带裂缝/反向法线/瘦三角的候选被当正式文件 |
| G21 | **10009019 直出 `.gia/.gil` 不携几何**（只 resourceId+变换）→ 正式产出必须走面板化（export-mesh / contour-model） | GIA/GIL 容器不含自定义网格，直出只有空壳（实测 c-mesh-direct 817B）。反例：直接拿 `gms.part('mesh')` 的导出当最终文件 → 地图里是占位/空壳 |
| G22 | **预算 = 单元数，1 面 = 1 元件**；`--budget <N>` 超限时被摘要/门禁拦截 | budget.used = 面板化产出的元件数（quads+tris+退化兜底盒）。反例：把预算当「原始三角数」，200 环×N 环就误判——面板化后才是单元数 |
| G23 | **放样 points 默认 64（设计预算档）**；要 200 点高保真需 `--no-gate` 并标注 | 盖扇三角 `minE/maxE ≈ 2π/points`；200 点 ≈ 3.1% < 8% → 门禁报瘦三角，64 点 ≈ 9.8% > 8% → 通过。反例：cap both + points 200 直接导出 → 门禁「瘦长三角占比超 5%」拒绝 |
| G24 | **焊接收敛 seam**：让网格顶点坐标在 `weldTolerance`（2e-4 m）内共享，而非仅靠「索引闭合」 | 重复坐标但不同索引的顶点是视觉/拓扑裂缝；与索引无关的近邻检测会抓 seam。反例：loft 环间顶点坐标差几毫米 ≠ 索引连续 → 门禁报「存在未焊接顶点」；焊接用共享顶点坐标 |
| G25 | **未校准基元先走校准板**：10009003/10009006/10009012/10009019 游戏侧语义未验证，产物按「候选」对待 | 未校准 = 朝向/双面/尺寸/空心/几何承载未在游戏验证，写「已闭合」是乐观假设。反例：把 10009003 当已闭合直接上曲面 → 若双面性/滚转与预期不同，整片曲面错；应先看 `docs/calibration-mesh-elements.md` 观察清单 |
