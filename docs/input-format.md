# 输入格式：structure.json 超集

`gen-model` 的输入是一个 JSON 文件（本仓库简称 **structure.json 超集**）。
它同时覆盖两层信息：

- **模型层**：名字、宿主模板、场景 Transform、ID 计划（prefabId / aux ID）；
- **装饰物层**（`items`）：每个官方基础元件的局部 Transform 与颜色。

生成器（参数化建模，后续迭代）的输出与手写输入共用同一格式：
**生成器 = 把高级描述展开成 `items`**。

## 顶层字段

| 字段 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `$schema` | string | 否 | — | JSON Schema 引用（一期仅为占位，不校验内容） |
| `schemaVersion` | number | 否 | 1 | 当前仅支持 `1` |
| `name` | string | **是** | — | 模型名；写入元件定义/实例名字（UTF-8），也是输出文件名 |
| `template` | string \| number | 否 | `"空模型"` | 宿主模板。一期只支持 `"空模型"`（或 `10005018`）；字符串必须是已知模板名 |
| `prefabId` | integer | 否 | `1077936129` | 自定义元件 ID（定义与实例共用）。**必须 ≥ 1077936129（0x40400001）**，见 [ID 规则](#id-规则) |
| `definitionAuxiliaryIds` | integer[] | 否 | 自动分配 | 定义侧装饰物 ID 列表，长度 = `items` 长度 |
| `instanceAuxiliaryIds` | integer[] | 否 | 自动分配 | 实例侧装饰物 ID 列表，长度 = `items` 长度 |
| `position` | number[3] | 否 | `[0,0,0]` | 场景层平移（米） |
| `rotation` | number[3] | 否 | `[0,0,0]` | 场景层旋转（度，编辑器 YXZ 内旋，见 [坐标语义](#坐标语义)） |
| `scale` | number[3] | 否 | `[1,1,1]` | 场景层缩放 |
| `items` | object[] | **是** | — | 装饰物列表，**至少 1 条**，见下 |

未知顶层字段报错（fail-closed）；`components` 与 assembly 级 `color` 属一期未覆盖
（显式报错，见 [一期未覆盖](#一期未覆盖)）。

## item 字段

| 字段 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `resourceId` | integer | **是** | — | 官方基础元件 ID（`[1e7, 1e9)`），见 [资源速查表](#资源速查表) |
| `position` | number[3] | **是** | — | 相对模型原点的局部平移（米） |
| `rotation` | number[3] | 否 | `[0,0,0]` | 局部旋转（度，YXZ 内旋） |
| `scale` | number[3] | 否 | `[1,1,1]` | 局部缩放（**尺寸语义随资源不同**，见速查表） |
| `color` | object | 否 | 不启用（默认材质） | 见 [颜色](#颜色) |

未知 item 字段报错。`resourceId` 一期只接受官方基础元件；自定义元件引用未覆盖。

## 颜色

```jsonc
{ "enabled": true, "rgb": "0xC8A87C", "opacity": 100, "overlay": "overwrite" }
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `enabled` | boolean | `true` 启用；`false` 表示整条只写 `{ "enabled": false }` |
| `rgb` | integer \| string | `0xRRGGBB`。JSON 没有十六进制字面量，推荐写字符串 `"0xC8A87C"`；也接受十进制整数（如 `13150332`） |
| `opacity` | number | 0–100（100 = 不透明；编码时换算 alpha 并回写 float 透明度） |
| `overlay` | string | `"overwrite"`（6700）或 `"multiply"`（6701） |

编码语义（已由 genshin-ts 用户核验闭合）：颜色写入装饰物 aux 的材质槽
`f5{f1:22}.f32`——`f1=1`、`f3=ARGB(varint)`、`f4=fixed32 透明度 float`、
`f5=RGB`、`f6=6700/6701`。**配置颜色必须写 `enabled:true` 全字段**；
不写 `color` = 默认材质（回读为 `{enabled:false}`）。

## ID 规则

- **自定义元件 def/inst/entity ID 必须 ≥ 1077936129（0x40400000 区间）**：
  游戏/编辑器只认该区间，`0x4000xxxx` 区间的元件加载时被整体丢弃 → 地图打开为空
  （2026-08-09 R4 空图根因，1874 已验证闭合）。`prefabId` 低于该值直接报错。
- **aux ID 无区间限制**：默认从 `1073741830`（0x4000xxxx）起按 items 交错分配
  （定义侧 `base+2i`、实例侧 `base+2i+1`）。
- 默认 `prefabId = 1077936129`：同一地图放多个模型时**必须显式分配**互不冲突的
  `prefabId`/aux ID（写回适配器负责与真实地图的占用双查：root 4/8/27 + root 5 实体）。
- aux ID 不得等于 `prefabId`，不得重复，**不得落在骨架占位 ID 上**
  （`1073741828 / 1073741829 / 1077936129 / 1077936130 / 1077936138 / 10009001 /
  10009002 / 10005018`——这些是模板替换占位，撞上会被替换过程破坏，校验直接拒绝）。
- 相同输入 ⇒ 相同输出（确定性）：输出无时间戳、无随机 ID。

## 坐标语义

- 长度单位：米。`1×1` 地格 = x/z 平面 `[-0.5, 0.5]²`，场景地面 `y=0`。
- 旋转为**编辑器 YXZ 内旋**：`R = Ry(β)·Rx(α)·Rz(γ)`，`rotation = [α, β, γ]`（度）。
- 两层坐标：模型层 Transform 决定整个模型在场景中的位置；
  `items` 的 Transform 是**相对模型原点的局部坐标**，不要混用。
- 浮点编码：位置/旋转/缩放写 float32（LE）；回读为 float32 精度（如 `1.39999997…`）。

## 资源速查表

官方基础元件 ID 与尺寸语义（已闭合项来自 genshin-ts 校准记录；
“未校准”= 一期仅登记 ID，可编码但不保证视觉语义，首次使用前先做最小校准板）：

| resID | 元件 | `scale=[1,1,1]` 语义 | 零旋转局部基 | 状态 |
| ---: | --- | --- | --- | --- |
| `10005018` | 空模型 | 无可见几何 | 作为宿主保存局部原点 | 已闭合 |
| `10009001` | 长方体 | `1×1×1`（边长 1 米，半尺寸 0.5） | X/Y/Z 对应三条边；`scale=[宽, 高, 长]`，长轴=局部 Z | 已闭合 |
| `10009002` | 球体 | 直径 1（统一设计语言） | — | 已闭合* |
| `10009003` | 平面 | `1×1` | — | 未校准 |
| `10009004` | 三棱柱 | 高 1，底面正三角形**外接圆直径 1**（外接半径 0.5，边长 0.866） | 高度轴 Y；底面 XZ；一个顶点朝 `-Z` | 已闭合 |
| `10009005` | 五棱柱 | 高 1，底面正五边形**外接圆直径 1**（外接半径 0.5，边长 0.588，顶点到对边距离 0.905） | 高度轴 Y；底面 XZ；一个顶点朝 `-Z` | 已闭合 |
| `10009006` | 三棱锥 | — | — | 未校准 |
| `10009008` | 圆柱 | 截面直径 1 | **零旋转轴向 Y（竖直）**；`scale=[截面直径, 轴向长度, 截面直径]` | 已闭合 |
| `10009009` | 圆锥 | — | — | 未校准 |
| `10009010` | 线框长方体 | — | — | 未校准 |
| `10009011` | 线框圆柱 | — | — | 未校准 |

\* 球体直径 1 属于“基础元件统一设计语言（scale=1 = 外接圆直径 1）”的一部分，
随 2026-08-09 用户实测修正闭合（旧“外接半径 1 / 边长 1”结论废弃）。

推导速记：

- 目标外接半径 `r` → 棱柱 `scale.x/z = 2r`；
- 目标边长 `s` → 三棱柱 `scale.x/z = s / 0.866`、五棱柱 `s / 0.5878`；
- 面片外贴 = 真实表面（`±0.5×scale`）+ 半厚 + 间隙 `0.005~0.01`（禁止 0 间隙/内嵌）。

## 示例

- `examples/house.json`：房子（长方体主体 + 三棱柱屋顶，X/Z 同比例保持三角形相似）
- `examples/box.json`：长方体 + 平面盖板（未配置颜色 item 展示默认材质路径）
- `examples/simple-assembly.json`：简单拼装（长方体 + 横放圆柱 + 旋转三棱柱 + 五棱柱）

- assembly 级 `color`（定义/实例整体材质）：骨架无材质槽，显式报错，请用 item 级颜色；
- 自定义元件作为 item 资源引用（`resolveItemResourceId` 逻辑已保留，仅官方资源放行）；
- 非空模型宿主模板（编码路径通用，但仅空模型经过真实地图/游戏核验）；
- `.gia` 输出：任务 B 负责（FR6）；写回真实地图：genshin-ts 适配器负责（本仓库只产出候选）。
