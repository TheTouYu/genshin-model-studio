## 1. 背景与决策（用户原话精神）

- 一次性生成整个模型有两个问题：① 太考验模型一次性能力；② 效果不好时人类只能反馈"整体不好看"，无法精确到每一步。
- 网页端支持实时渲染 → 每添加一笔，人类都能立即看到效果并给出反馈（视觉、旋转、颜色、尺寸缩放等）。
- 实现方式：网页暴露**程序化建模命令层（window.gms）**，AI 通过命令逐笔添加笔画、改参数；命令参数预先设计好，人类可精确指正（"这个圆的尺寸不对 / 颜色不对 / 位置不对"）。
- 命令库**渐进式扩充**：先固化一批基础命令，使用过程中缺什么补什么，一次一次增加。
- 协作闭环：AI 调命令画一笔 → summary + 截图供人类看 → 人类反馈 → AI 修正/画下一笔。

## 2. 交付物

### 2.1 window.gms 程序化建模命令层

在 web/index.html 的 IIFE 内定义、挂到 `window.gms`（复用内部函数，不改变现有 UI 逻辑）。所有命令返回最新 `summary()` 供审核；参数非法时抛**中文错误**（说明原因和当前值）。

**命令表**（坐标均为画布像素；opts 见下）：

| 命令 | 参数 | 说明 |
|---|---|---|
| `gms.clear()` | — | 清空作品（等价清空按钮） |
| `gms.undo()` | — | 撤销上一批（等价撤销按钮） |
| `gms.circle(cx, cy, r, opts?)` | 圆心 + 半径 | 画圆（24 等距点 + 闭合点，与圆工具同构） |
| `gms.rect(x0, y0, x1, y1, opts?)` | 对角两点 | 画矩形（4 顶点 + 闭合点） |
| `gms.line(x0, y0, x1, y1, opts?)` | 两点 | 画直线 |
| `gms.curve(pts, closed?, opts?)` | 控制点数组（≥2） | Catmull-Rom 采样；closed=true 时闭合 |
| `gms.loop(pts, opts?)` | 轮廓点（≥3） | 自由笔闭合轮廓（autoClose 拉齐首尾） |
| `gms.props(i, opts)` | 笔画索引（负数=倒数） | 设渲染/高度/方向/颜色，立即重生成 |
| `gms.rotate(i, cx, cy, n)` | 索引 + 旋转中心 + 份数(2~12) | 旋转复制，含源共 n 份（副本插入源后，一个撤销批次） |
| `gms.delete(i)` | 笔画索引 | 删除笔画 |
| `gms.summary()` | — | 状态栏文本 + 每笔索引/参数/bbox（px 与米）+ 全局选项 |
| `gms.px2m(px)` / `gms.m2px(m)` | — | 尺寸换算（按当前标定） |
| `gms.export()` / `gms.import(data)` | — | 作品 JSON 导出 / 导入并重生成 |

**opts 字段**（每个命令可选）：
- `render`: `'solid'`（柱体）| `'rod'`（杆，缺省）——注意有效值是 rod 不是 line
- `height`: 米（正数）——solid 笔画 = 柱体高度；rod 笔画 = 抬升高度（z）
- `axis`: `'up'`（缺省，不写字段）| `'front'` | `'side'`
- `color`: `'#hex'`（缺省 = 当前选中色）

**尺寸语义**：标定 = `options.canvasHeightPx` 像素对应 `options.heightMeters` 米（当前作品 320px = 1m）；每笔模型尺寸 = 像素 × heightMeters / canvasHeightPx。`summary()` 的 bbox 同时给 px 和米，供人类对照审核。

### 2.4 旋转成型（lathe 无缝化，用户五期补充需求）

用户建模水杯的思维路径：① 用多个长方体把杯壁的曲线轮廓拼出来（分段逼近母线）；② 让这条线绕轴旋转成杯身；③ 旋转时大小/角度算不准会产生裂缝、间隙，必须能调到无缝闭合。当前版本缺这个能力（画完自动车削，但输出是 48 条 BOX 拼接——棱面、接缝、锯齿杯口，视觉不合格）。

**新增资源 10009012 开口薄壁圆柱（OPEN_CYLINDER）**：
- mesh：`CylinderGeometry(0.5, 0.5, 1, 48, 1, true)`（openEnded，48 段圆周）＋双面材质（杯口看进去能看到内壁）。
- 语义：零旋转轴向 Y；scale = [截面直径, 轴向长度, 截面直径]；**无缝闭合**（单 mesh 旋转体，无接缝/无棱/杯口光滑开口）。
- 定位：与圆柱（10009008）同规则，但**空心**（无顶盖无底盖）。

**lathe 模式输出改为单个 OPEN_CYLINDER**（取代 48 条 BOX 壳条）：
- 半径 = 母线等高度归并后的最宽半径（`sampleByHeight` 保留）；高度 = 笔画自身包围盒高；位置 = 旋转轴（笔画 minX）居中。
- 局限（PRD 明示）：当前按最宽半径出直筒，曲线轮廓（花瓶式上宽下窄）暂不还原；后续用多段 OPEN_CYLINDER 拼接逼近。

**gms.opts 新增字段**：
- `segments`（圆周细分段数，默认 48，越大越圆）：`gms.props(i, {segments: 96})` 可调，**保证无缝闭合**（单 mesh 旋转体不存在接缝；段数只影响圆滑度）。
- `axis`（旋转轴 x 坐标，缺省 = 该笔画画布 bbox 左缘）：`gms.props(i, {axis: 300})` 可把母线绕指定轴车削（旋转半径 = 母线到轴的距离）。

**验收**：杯壁渲染 = 单个无缝光滑开口圆筒（无棱条、无接缝、杯口开口可见内腔）；壁底贴杯底；把手 rod 不再被 height 抬升悬空（rod 的 height 语义 = 抬升 y，把手不传 height，y 由画布坐标定）。
