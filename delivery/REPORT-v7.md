## 1. 端口高度 bug（研究会话转达的用户像素实测反馈）

用户/研究侧报「`ports.centerY = 4.4mm` 定低了，端口贴底」。核实后确认方向正确、数值需修正，且根因比单参数更深：

| 项 | 旧 | 新 | 依据 |
|---|---|---|---|
| `ports.centerY` | 4.4mm（28%） | **7.7mm（49.7%）** | 官方 ports-1/2/3 三图交叉：开口中心恒 y=62.5px、上盖/底座分缝恒 y=38.5px → 24px ÷ 6.04px/mm = **3.95mm 距分缝**；标尺由 USB-C 开口宽 50px/8.34mm 与侧高 92.3px/15.0mm 互校；design-reference §7.2 独立实测 3.79mm 同口径 |
| `base.h` | 11.5 | **10.95** | 旧值把脚垫 0.55 又加一次 → 整机 16.05mm（官方 15.5） |
| `lid.closedY` / `hinge.axisY` | 12.35 | **11.8** | 台面 11.5 + 闭合缝 0.3 → 上盖顶 15.5 ✓ |
| 端口 z（整簇） | 跨 126mm | **跨 46mm** | 朝向整簇反转：**MagSafe/HDMI 靠转轴、jack/SDXC 靠前缘**（三份用户参考图证据） |
| HDMI 开口高 | 5.8 | **4.5** | = HDMI Type-A 插头高 4.45；实测暗区 28px/6.04=4.6 |

研究方用「紧凑暗段过滤」独立复核：左槽中心距底 8.1mm / 右 7.9mm，与 7.7（距台面）吻合，原 6.0 系阴影带污染，已作废。

顺带修：圆孔变十字块（`zToU` 1024 步 = 1mm 栅格 → 16384 步 + jack 13 档断点）、v 断点被 `snapB` 吃掉（改按真实 y 距去重）、USB-C 内舌贴开口（推深 1.6mm）、MagSafe 误带内舌（删）。
详见 `delivery/REPORT-port-fix-r5.md`。

## 2. 传感器噪声：判官 E5 的真根因（本轮最大工程发现）

判官三轮一致指出「平坦区零噪声 / 周期性斜向点阵」。定位过程：
- 渲染 `noise=0.0 / 0.03 / 1.0` 三档 → **平坦区 3×3 残差 SD 恒为 0.099，而整图亮度随 noise 平移**（0.03 时 −2，1.0 时 −68）。
- 即噪声项实际输出**常数**：`hash(uv * uRes + vec2(uSeed * 37.0, uSeed * 91.0))`，`uSeed` = shotSeed（≈2×10⁷ 整数）→ `uSeed*37 ≈ 7.5×10⁸`，float32 在该量级的分辨率约 **64** → `fract()` 的小数部分全被吃掉。
- 修法：先把 seed 折进小范围（`fract(uSeed*0.000103)` 等）再乘系数；并加红/蓝独立色度噪点（占比 0.18）。

**验收读数**：平坦区 3×3 残差 SD **0.099 → 0.950**；参考图同口径：俯视图 0.807、正视图 0.787、13" 底盖 0.482（暗底图 5–12，已按预设分档：白底 0.030 / 灰底 0.035 / 暗底 0.09）。

**判官点名的剩余破绽（本轮已修，待 v8 复测）**：
1. 键槽亮灰 → 真机键盘井是黑的（参考图实测 rgb(15,14,14) vs 我 rgb(194,193,192)）→ `M.WELL` 独立材质（比键帽更黑）；
2. 数字行 5/6/7/8 缺 %^&* 上档符号 → 字标合成器的行组清理规则误删（按行组数分档修复）；
3. 触控板缝 z-fighting"断续虚线" → 共面微偏移 0.06 → 0.25mm；
4. 苹果叶形"尖窄杏仁" → 叶子抽稀从 maxSeg 1.2mm/8° 改为 0.30mm/30°（176 点保留曲率）；
5. 底盖"无螺丝/无法规文字/脚垫平涂圆" → 脚垫加微穹顶+环状高光、新增激光刻蚀文字块（3 行 34 段细横条，`M.ETCH`）。
