## 2. 裁判指令（固定，逐字使用）

> 你是一名产品摄影鉴定师。目录 `.blind-<seed>/` 内有 12 张图片（img01..img12），
> 每张要么是**真实拍摄的产品照片/官方产品图**（photo），要么是**CG 渲染**（render）。
> 逐张独立判断，给出 verdict（photo|render）、confidence（0-1）、一句话依据。
> **禁止读取该目录以外的任何文件**（包括脚本、交付目录、文档）。输出 JSON 数组。

## 3. 口径

- 达标线 = **误判率 ≥ 50%**（3 位独立裁判 × 12 图 = 36 次判定；误判率 = 判错数/总判定数）。
- 我方 6 张全部来自**真实浏览器页面截图**（`web/draw/photo.html` + `__photo.shoot()`，
  `canvas.toDataURL` 直读像素），无任何后期处理。
- 图集统一重编码 PNG、长边 ≤ 880px、随机混排（seed 决定）、key 不落盘。
- 裁判 = 全新独立子代理（无本会话上下文）。

## 4. 本轮（v6 → v7）已修

| 问题 | 修复 |
|---|---|
| **传感器噪声实际是常数**（判官 E5「周期点阵/零噪声」的真根因） | `photo.html` 噪声 hash 的 seed 折叠错误：`uSeed*37 ≈ 7.5e8`，float32 在该量级分辨率 ~64 → `fract()` 全被吃掉，on/off 差恒为 −68（整图平移而非噪声）。改为先把 seed 折进小范围。实测平坦区 3×3 残差 SD **0.099 → 0.950**（参考图 0.48–0.81） |
| 色度噪点缺失 | 新增红/蓝独立色度噪声（占比 0.18） |
| 六图同画布 | 每视角独立画布尺寸（见 §1） |
| closedtop 机身被画框裁掉两侧 | dist 0.385 → **0.550**（0.385 时可见宽 256mm < 机身 312.6mm） |
| 底面被裁 | dist 0.40 → **0.50** |
| 屏幕正面过近 | dist 0.40 → **0.44** |
| Apple 标读作灰苹果 | logo 材质 metalness 1.0/roughness 0.14/env 1.45 → **0.90/0.26/2.10**，色改纯白 |
| 端口高度/朝向（研究会话报的真 bug） | `ports.centerY` 4.4 → **7.7**（距分缝 3.95mm）、整机高 16.05 → **15.5**、端口 z 朝向整簇反转（MagSafe/HDMI 靠转轴）、HDMI 开口高 5.8 → **4.5** |
