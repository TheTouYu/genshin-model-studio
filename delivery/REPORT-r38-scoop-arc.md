## 工具先行（用户指定）：`scripts/max/deck-qa.mjs` 升级

| 新增 | 作用 |
|---|---|
| `--profile` | 打印横向 depth(x)（最深行）与进深 depth(z)（x=0）真实剖面 + 平台占比 + 肩部斜率 + 二阶差分/曲率半径 |
| `plateau_pct` 判据 | >45% = 平底方槽（即用户说的「弧度几乎没有」） |
| `shape` 判据 | 剖面分别按**弧**（余弦/抛物线，拱心与半宽一起拟合）与**平底方槽**拟合，取残差小者为形状；门禁 = 弧残差 ≤20% 且 <0.6×方槽残差 |
| `--probe x,z` | 打印局部高度场（0.25mm 网格），查 step/kink 报警点到底是什么坡 |
| `--hits x,z` | 打印该射线的**全部命中层 + 颜色**（近乎共面的两层几何互争像素的诊断） |
| 触控板排他区 | \|x\|<68 且 z<102.3 不参与判据（它是独立玻璃板，0.25mm 凸台会被误判成 step） |
| 口径修正 | step 改按**斜率**门（0.25mm 网格上 0.05mm 绝对高差 = 11° 坡，会把正常进深坡全判失败）；真正的不连续台阶由 kink（二阶差分）抓；jag 门按网格尺度放宽到 0.40/mm |

## 几何修复（`src/model/macbook/geometry.ts` SCOOP 段）

- 沿 x 的深度分布 `(1-t)/0.45` 截断 smoothstep → **余弦拱 `0.5*(1+cos(πt))`**：旧值在 |x|≤14mm 全是 1.0 的**平台**（实测横向剖面 −11..+14mm 恒 2.59mm → plateau 92%）。
- `SCOOP_D 2.7 → 1.5`（用户要求减深）；`SCOOP_RAMP 9.0 → 8.0`：zStart = 110.6−8 = **102.6**，必须落在触控板**暗缝环前缘 101.95mm 之外** —— RAMP=9 时下沉正好从 101.6 起，暗缝环（独立扫掠件、y=deckY+0.12、不参与下沉）前缘被露在沉下去的台面之上 → 渲染出 **V 缺口 + 一排阶梯块**（出图实测）。
