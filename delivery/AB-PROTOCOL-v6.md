## 2. 裁判指令（固定，逐字使用）

> 你是一名产品摄影鉴定师。目录 `.blind-<seed>/` 内有 12 张图片（img01..img12），
> 每张要么是**真实拍摄的产品照片/官方产品图**（photo），要么是**CG 渲染**（render）。
> 逐张独立判断，给出 verdict（photo|render）、confidence（0-1）、一句话依据。
> **禁止读取该目录以外的任何文件**（包括脚本、交付目录、文档）。输出 JSON 数组。

## 3. 口径

- 达标线 = **误判率 ≥ 50%**（3 位独立裁判 × 12 图 = 36 次判定；误判率 = 判错数/总判定数）。
- 我方 6 张全部来自**真实浏览器页面截图**（`web/draw/photo.html` + `__photo.shoot()`），
  无任何后期处理（仅 `canvas.toDataURL` 直读像素，不经 captureScreenshot）。
- 图集统一重编码 PNG、长边 ≤ 880px、随机混排（seed 决定）、key 不落盘。
- 裁判 = 全新独立子代理（无本会话上下文）。

## 4. 本轮（v5 → v6）已修

| 问题 | 修复 |
|---|---|
| 键盘井底是近黑（真机是阳极氧化铝） | `geometry.ts` 井底材质 `M.KEY` → `M.ALU` |
| Apple 标三角形错挂屏幕材质（55 tris），页面把它当屏幕贴桌面纹理 | `b.material(M.LOGO)` + 页面加镜面材质分支 |
| 白底背景被 ACES 压到 221（真白底是 255） | 背景改为**色调映射之后**合成（RT alpha 合成），实测 254.5 |
| 影棚环境被 `scaleEnv` 把**颜色**也乘了倍率（0xcfcfcf×0.46=蓝） | 只缩放强度字段（ENV_INT） |
| 上盖过曝（p50 242）| 环境强度 + 曝光标定：闭合上盖 lid mean 212.9 vs 参考 213 |
| 底视图穿透（镜像组横在相机与模型之间） | `applyView` 中相机 y<0 时隐藏镜像组 |
| 触控板近黑（参考图里比掌托更亮） | 模型材质 0.030→0.28 linear + 页面玻璃分支 |
| fn 行 14 键宽 15.0u > 键盘块 14.65u（右端穿出 6.45mm） | `spec.ts` 每键 1.04643u |
| 屏幕贴图是截图中心裁切（只剩白 Finder 窗） | 改用整张 `亮屏桌面.png` 按屏幕宽高比取中心 |
