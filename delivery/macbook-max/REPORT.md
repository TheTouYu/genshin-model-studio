## 2. 验收：同角度 A/B 盲测（独立模型，去标识混排）

- 12 张（6 自渲染 + 6 官方参考）随机混排于 `delivery/macbook-max/ab-test/`
- 评委：独立子代理（无本会话上下文），仅凭图像内容判定 photo / render
- 通过线：**误判率 ≥ 50%**

| 轮次 | 修复内容 | 评委误判率 | 结论 |
|---|---|---|---|
| r1 | 首版 | 0% / 0% / 0% | 全部被识破 |
| r2 | 去掉 Bayer 抖动指纹 + 传感器噪声（亮度主导）+ 屏幕 UI 重做 | 0% / 33% / 0% | 仍被识破 |
| r3 | 上盖加长（闭合时不再露出键盘）+ 底盖螺丝/雕刻 + 端口腔体加深 + 超采样 + 噪声 RNG 修复 | **41.7% / 16.7%** | **未达 50%，判定：未完成** |

评委的决定性证据（可复现）：JPEG 8×8 相位（真图）vs 白噪声变差函数（渲染）、色度/亮度噪声比、孤立萤火虫点、行奇偶交织伪影、真机上的法规雕刻/螺丝/灰尘等微细节。

## 3. 已知最弱环节（下一轮）

1. **噪声统计仍非相机统计**：渲染的残余采样噪声变差函数接近白噪声（真图有 8×8 JPEG 结构与亮度主导的颗粒）。→ 需要：更好的采样（分层/Sobol）+ 显式胶片颗粒模型 + 输出端 JPEG 编码器（零依赖自写）。
2. **微细节缺失**：底盖法规雕刻/通风口、端口内腔的金属反光层次、键帽字符在小尺寸下仍偏"糊"。→ 需要：更高分辨率字符图集或矢量字形、雕刻用几何而非贴图。
3. **屏幕 UI 是程序化合成**：评委反复指出"garbled glyphs / fake wallpaper"。→ 需要：真实 macOS 截图的纹理管线（或放弃屏幕内容，改拍闭合/侧面角度）。
4. **渲染速度**：~1.7 Ms/s（8 核），单张 900×620 超采样图约 50 s。已从 124k 三角降到 79k、BVH 有序遍历、灯光预计算；仍可做 SIMD/波前路径。
