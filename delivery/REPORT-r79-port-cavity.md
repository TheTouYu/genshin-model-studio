# R79 接口 v7 —— 可见边界 = 开口真实轮廓（挖孔方案第三次尝试，成功）

## 1. 起因
用户判 v6（挖大孔 + 领圈盖毛边）不通过：「你修换了接口，如果不能快速找到问题，就先回滚代理继续分析」。
回滚（`557208f`）后用户令「继续吧」→ 本轮按新方案重做。

## 2. v6 病根（已取证，`delivery/r78/`）
按**格心**挖大孔（`portCutMask` + `PORT_CUT_GROW=0.6`）→ 孔边只能是网格步长的台阶；
再用一块凸出 0.02mm 的**领圈**去盖台阶 → 近轴特写（elev 3°）看着没问题，
**斜视（elev −10°）时孔边毛边落在领圈之外** → 直接看到 2mm 腔体内部 = HDMI 左端"阶梯"、SDXC 端"黑楔"。
`ray-pick` 证明黑楔像素首命中 `#1d1d1e @ x=154.3–155.58`（腔底），不是墙面。

## 3. v7 方案（三步）
1. **整格矩形窗口**：端口窗口 = 开口外接盒 + 1.6mm，四条边**注入成全局 u/v 格线**
   （`uBreaks.push(zToU(zA/zB))`、分段循环里 `vs.push(vForY(yA/yB))`）→ `patch(..., {mask})` 按格心删掉的
   正好是整格 → **零毛边**，不再需要任何补片/领圈。
2. **墙板回填**（`portWallPlate`）：
   - 左/右带：窗口同侧边沿 ↔ 口沿**细链**，每个外沿段用**扇形**连接中间的细链点；
   - 上下横带：相切线以外到窗口边，整幅宽度；
   - 外沿按 ≥0.30mm 抽稀（**> 焊接容差 0.2mm**），两端点再与相邻点拉开 >0.22mm。
3. **孔边顶点直接落在墙平面**（`onRim`：`x = ±B.w/2`），与 `portOpening` 的腔壁**逐位相同** →
   page-mesh 焊接只会把它们并成同一个点（位置不变）→ 边界零偏移。
   腔体保留：口沿 → 腔底 2mm（`DEPTH`），内舌/触点离口 1.10mm（`DETAIL`）。

## 4. 新尺子：`scripts/max/wall-scan.mjs`（已资产化）
沿每个口的**解析轮廓**取 260 点，沿外法线二分求「近侧墙面 → 非墙面」的过渡点，
量它相对真轮廓的偏移；另量开口中心的首命中深度（应 = DETAIL/DEPTH）。
口径与真机一致：0.03mm ≈ 0.8px @ 27px/mm（逐口特写尺度）。退出码 1 = 有超差。

| 口 | R79 前（v6 回滚前的挖孔版） | R79 后 |
|---|---|---|
| L-magsafe / L-usbc×2 / L-jack / R-hdmi / R-usbc / R-sdxc | 601/1820 失败，最差 **0.463mm** | **0 失败，最差 0.014mm** |

**尺子抓到的真 bug（换算法必须换尺子）**：`portOutlineZY` 把每一端写成**一条 180° 大弧**
（圆心 `(ax,0)`）—— 在 `rr = hh` 的 stadium（USB-C/MagSafe）上正确，但在 `rr < hh` 的圆角矩形
（HDMI R0.9 / SDXC R0.9）上，角区边界内缩最多 `rr = 0.9mm` → 腔体口沿比墙板孔边小一圈 →
角上留下最宽 ~0.23mm 的**进机身的缝**。已改为标准圆角矩形（4 直边 + 4 个各 90° 角弧）。

## 5. 修程中被「焊接容差 0.2mm」反复咬（四条，均已写进代码注释）
| # | 现象（尺子实测） | 根因 | 修法 |
|---|---|---|---|
| 1 | 相切处假边界 0.147mm | 口沿点距 0.098mm < 0.2mm → 带内外顶点互焊，四边形塌陷 | 外沿抽稀 ≥0.30mm，内沿保留细链 |
| 2 | 同上（守卫失效） | 守卫量的是**链上弦长**（0.35mm），不是外沿顶点间距（0.09mm） | 改量 `|Δy|` |
| 3 | 开口四角被堵 0.30mm | 恰好落在相切线上的行，半开穿越规则数不到交点 → 该带整幅铺墙 | 相切行向内 1e-3mm 回退取样 |
| 4 | 横带边缘下沉 0.09mm | 横带角点被焊到相邻外沿点 | 外沿两端点与相邻点拉开 >0.22mm |
