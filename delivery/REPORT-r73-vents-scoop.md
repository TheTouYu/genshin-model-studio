# R73：侧壁散热槽（新建）+ 前缘凹槽下凹感减弱

用户口令（逐字）：①「'下凹感'需要减弱」 ②「做侧壁散热」

## A. 侧壁散热槽 —— 新增几何
**参考标定**（官方 `reference/macbook/img/official-mbp14-connections-1/2.jpg`，3772×300）：
- 标尺 **17.02 px/mm**，用四个端口中心交叉验证：USB-C1 预测 x=792.8 / 实测 792.5；USB-C2 1044.7 / 1050；
  jack 1262.6 / 1266.5 → 映射 `x = 1885.5 + 17.02·z` 误差 ≤0.3mm。
- 槽范围：**后端正圆帽 z=−20.1、前端正圆帽 z=+84.4**（长 104.5mm）；右壁（ports-2，5.97px/mm）后帽 z=−20.3 ✓ 两侧对称。
- 槽中心 ≈ 底面之上 **1.25mm**，槽高 ≈ **0.9mm**；它坐在底缘倒角（R1.55）的曲面上。
- 槽下方紧跟一条亮边 = 底缘倒角本身的高光（由机身扫掠提供，不另画）。

**实现**（`src/model/macbook/geometry.ts` 新增 `wallSlot()`，与 `portOpening` 同族「贴面件」口径）：
- 不切墙；贴面沿剖面 `o(y)` 插值贴合底缘倒角曲面，凸出墙面 **0.06mm**（0.05 以下掠射有穿透斑纹）。
- 端帽 = 半圆三角扇，扇心取**半圆圆心**；绕序同时看 `side` 与 `dir`（照抄 r32 教训）。
- 新增 `M.VENT`（baseColor 0.020/0.020/0.022 → 页面 hex **0x272729**）；槽内**下唇**用 `M.ALU_DARK`
  做一片朝上倾斜的窄面（下缘后退 0.10mm、上缘与暗片齐平，高 0.22mm）——真机照片里槽不是纯黑线，
  而是「上暗下亮」，下唇吃到主光形成细亮线。
- 踩坑：① 端帽 `cseg` 原取 14 → 弧点间距 0.10mm **小于 page-mesh 焊接容差 0.2mm** → 弧点被合并、
  退化三角形被去 sliver 丢掉（60→24 面）；改 `hq(5,3)`（点距 0.278mm，多边形误差 r(1−cos18°)=22µm）。
  ② `V()` 里 `side` 用了两次（`side*(wallX-(o-P))`）→ 两条槽都落到右壁重叠；改 `wallX - side*(o-P)`。

**验收读数**（page 网格）：左右各 12 面（矩形 2 + 两帽 5×2），
`x=±156.26…156.36 / y∈[1.35,2.25] / z∈[−19.98,84.38]` mm；下唇 4 面 `y∈[1.35,1.57]`。
渲染（2375 宽画布、20.3 px/mm 口径）实测：后帽 z≈−19.7 ✓、前帽 z≈+84.8 ✓、槽高 14–15px≈0.7–0.9mm ✓、
槽心距底面 1.38mm ✓。目视对照 `delivery/r73/vent-vs-official.png`（上=官方银色右壁，下=我的左壁同 z 区间）。

**代价（如实）**：贴面件 = 无真实腔深（与端口同一取舍，R29-9 待用户裁决）。

## B. 前缘凹槽下凹感减弱
- `SCOOP_D 1.5 → 1.0mm`（宽度 51mm 来自参考实测，不动；余弦拱与两端余弦肩不变）。
- deck-qa（`--z1 109` 排除最前 1.6mm 的边界行）：**depth 1.544 → 0.949mm**、holes 0、kink_max 0.085、
  kink_px 0、step_max 0.099（斜率 0.199 < 0.6 门）、shape=**arc**（弧残差 14.4% vs 方槽 38.1%）、肩 3.5°。
- 诚实记录：`plateau_pct 55.6% > 45%` 门被判 FAIL —— 该门是「|dD/dx|<0.05 的格占比」，阈值固定，
  浅拱的中心区天然落进阈值内，**不是平底方槽**（shape 判据明确判 arc）→ **门本身对深度不具尺度不变性**，
  这条不当"通过"用，留给用户看图定。
