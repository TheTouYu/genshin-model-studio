# R77 — 接口第二轮：贴面件 → 真实浅盲孔 + 暗内壁

用户 2026-09-11 选定：「端口二轮：贴面件 → 浅盲孔 + 暗内壁（推荐）」（R29-9「贴面 vs 真腔深」的中间路线）。

## 结论

7 个接口（L: MagSafe / USB-C ×2 / jack，R: HDMI / USB-C / SDXC）从「贴在墙面上的深色薄片」
（v4，零腔深）换成 **真实 2.0mm 盲孔 + 深色内壁 + 内舌/触点**，开口尺寸按设计值逐口实测一致，
无穿透、无锯齿、无共面色差；**整机其余部分与改动前逐像素一致**（A/B 见下）。

## 结构（`src/model/macbook/geometry.ts` · `portOpening` v6）

1. **墙体挖孔**：`portCutMask` 按**开口放大 `PORT_CUT_GROW = 0.6mm`** 判定（`patch` 的 mask 只在
   格心采样，孔边必然带 ±半格 ≈0.2mm 毛边；孔放大后毛边整圈落在开口之外）。
2. **领圈** `COLLAR = 1.6mm`：一圈**与墙同材质同法线**的浅锥环（内缘 = 开口尺寸 O、凸出 0.02mm；
   外缘 = O+1.6 落在**墙面平面上**，1.4° 锥 ⇒ 外缘无台阶）→ 盖住毛边，可见边界 = 光滑的
   圆角矩形/胶囊/正圆轮廓。
3. **腔体**：桶口(O) → 侧壁 → 腔底（深 **2.0mm**）+ 内舌（USB-C/HDMI/SDXC）/ 5 触点（MagSafe）
   在进深 1.10mm；jack 只有暗腔（真机无内舌）。桶是**封闭**体 ⇒ 任何角度都看不到机身内部。
4. `emitTriN/emitQuadN`：按**期望的可见面法线**决定绕序（腔壁内表面法线朝腔内，不是朝外）。

## 关键工程约束（写进代码注释，别再踩）

- **焊接容差 vs 细节尺度**：`page-mesh.mjs` 的焊接容差 0.2mm（历史值）会把 0.02mm 唇口、
  0.17mm 弧形弦长整圈焊退化成洞 → 射线穿过开口打到机身底板（实测 `nHit=1 @ y=0.55`）。
- 解法 = **两级焊接**（`page-mesh.mjs`）：端口区（`|x|>150mm, y 3..12.5mm, z -96..-28mm`）用
  `2e-5 m`，其余区域保持 `2e-4 m`。全局调细会让**前唇凹槽带**那层与扫掠面贴 0.1–0.2mm 的
  薄双层各自留面（一侧解析法线斜面、一侧 (0,0,1) 平面）→ 前壁点状虚线（A/B 实测 164px）。
- **宽度采样不等于高度采样**：`portFracs` 的分数由 `(w/2-h/2)/w` 得来；SDXC（w=27.2,h=2.55）时
  全落在 0.45..0.5 ⇒ 开口上下各只采样 0.12mm ⇒ 格高 0.3–1.1mm ⇒ 毛边超出领圈 ⇒ 开口下方
  一条 1px 亮线。修法：对宽口再补一组**按高度**算的分数（6 段→12 段）。
- **近重复点**：`portOutlineZY` 的 `rr = min(hh,hw)-0.01` ⇒ stadium/正圆两端「端边点」与
  「弧端点」相距 0.02mm ⇒ 0.02mm 宽细条三角 ⇒ 光栅化成**点状亮线**（MagSafe 开口内那条
  自触点斜向下的虚线）。修法：剔除 < 0.05mm 的近重复点。

## 未闭合 / 如实说明

- 腔内容貌仍是「均匀深色」：真机腔口有一圈**亮色金属倒角**、USB-C 有金属屏蔽壳。本轮只做了
  暗内壁 + 内舌/触点（用户选定项），亮色倒角未做（做成亮色环有「贴片色差」风险，v3 的画框
  教训在前，需另设机位单独验）。
- 犄角约束：领圈/挖孔尺寸与 `page-mesh.mjs` 的两级焊接容差**耦合**（改动其一需同步复核端口）。
- 触点/内舌是单层 quad（无厚度）；jack 无内腔套筒细节。
- 端口**开口**的倒角宽度未与真机逐像素比对（真机腔口倒角 ≈0.2–0.4mm 亮边）。
