# r11 报告：合盖「上下齐平」尺寸修正（用户 2026-09-10 第二轮反馈）

用户原话（本轮验收口径）：

> 「这个问题，我圈出来的地图，严重没有对上，我也查了官方的一些截图，盖着的时候，上下两面是完全大小相等的。苹果的设计不会出现这种没有闭合的情况啦，官方 14 寸两种颜色的情况，都是绝对对齐的。」
> 「上下盖子平齐，上盖需要左移对其下盖，尺寸可能错了。」

证据图：①我方 MagSafe 特写（红圈：开口两侧垂下的「梳齿」）②我方合盖左前 3/4（红圈：上盖左缘与底座的缝）③官方 14″ 双机（深空黑 + 银）合盖俯视图。

---

## 1 根因：上盖深度少 8mm（主要）

`spec.ts` `lid.d` = 210.0。上盖前缘 110.4 固定 → 后缘 −99.6，而底座后缘 −110.6 → **合盖俯视露出 11mm 台面 + 转轴槽**。官方俯视图里上盖轮廓就是整机轮廓，后唇几乎不可见。

**修法**：`lid.d` 210.0 → **218.0**（后缘 −107.6）、`hingeZ` −99.6 → **−107.6**（转轴轴心 = 上盖后缘）、`hinge.rodZ` / `slot.cz` −102.8 → **−106.6**（槽藏到合盖后的上盖后缘之下；槽 −108.6..−104.6，与台面后缘 −109.25 留 0.65mm 桥）。

**实测（导出网格顶点包围盒）**

| | 旧 | 新 |
|---|---|---|
| 上盖 z | −99.60 .. 110.40 | **−107.60 .. 110.40** |
| 底座 z | −110.60 .. 110.60 | −110.60 .. 110.60 |
| 后唇 / 前唇 | 11.00 / 0.20 mm | **3.00 / 0.20 mm** |
| 上盖 x | ±156.30 | ±156.30（= 底座，含 0.02mm 端口补片为 ±156.32） |

## 2 前缘开盖凹槽符号反了（第二处外凸）

`geometry.ts` 的 `surf()`：

```ts
return v3(p.x + pt.nx * g, p.y, p.z + pt.nz * g);   // 沿外法线 +g = 外凸
```

`pt.nx/pt.nz` 是轮廓外法线，`+g` 把前壁中段**外推** 1.5mm → 底座 z 到 **111.50**（名义 110.60），合盖时底座比上盖多出整整一圈台阶（用户圈的那条「对不上」）。改成 `−g` 内凹，深度 1.5 → 1.2mm。修后底座 z max = **110.60** ✓。

## 3 底面螺丝吊在底面之下

旧版螺丝组整体在 `B.bottomY − 0.75 … − 0.30`，即整机 y 最低到 **−0.20mm**（底面看是四个凸点，侧视后缘多一层）。改为与底面齐平（沉入 0.02mm，底视仍可见）。修后整机 y min = **0.00** ✓。

## 4 端口两侧「梳齿」条纹（用户上一轮圈的那处）

逐层取证：

1. **不是** PBR 材质问题——换 `MeshBasicMaterial`（无光照）条纹消失，换 `MeshNormalMaterial` 条纹呈品红（法线朝内）。
2. **不是** 腔体几何——把 `port-cavity` 整组隐藏，条纹仍在。
3. **射线定位**：条纹像素的首命中是 `y = 0.55` 的**底盖内表面**（法线 (0,1,0)），不是墙面 → 墙体在那些像素上**没有三角形**。

根因：墙体开孔用 `patch()` 的**格子 mask**（按格心判定），孔边是阶梯状；阶梯处格子被多删 → 直接看进机身内部，内部铝面反射环境（金属 IBL）→ 开口两端垂下亮条纹。

**修法**：新增 `portBezel()` —— 在壁面外侧 0.02mm 铺一圈**平面环**（外边界矩形 → 内边界精确圆角开口，径向映射），把阶梯整片盖住；mask 开孔额外外扩 0.4mm 保证补片必然覆盖；端帽采样分数 12 → 6 段（孔边不再由墙体负责，省三角）。

**二次 bug**：补片第一版绕序反了 → three.js `DoubleSide` 对背面翻转法线 → 补片整片变暗（射线取证 `face.normal = +x`）。翻绕序后 `face.normal = (−1,0,0)` ✓，补片完全不可见。

修后：开口为精确圆角矩形（r 1.15mm），墙面无亮条；特写里只剩 3–4 条极细的残余（阶梯齿的轮廓光），在验收分辨率（880–1180px）下不可见。
