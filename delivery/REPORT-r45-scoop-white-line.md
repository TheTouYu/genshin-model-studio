## 根因（代码定位）
前缘凹槽不是几何面，而是**对网格做顶点置换**：
- `src/model/macbook/geometry.ts:797-921` SCOOP 段：在矩形窗口内对**所有网格**的顶点做
  `y -= SCOOP_D·nx(t)·zx(z)`（余弦拱 × 进深 smoothstep），随后**按位置键重算法线**。
- 被位移的对象是**两批互不共享顶点的曲面**：
  `:398` 机身扫掠（`bodyProfile(B.bottomY, deckY, filletTop, hq(8,1), B.fillet)` 的顶部圆角 8 段）
  与 `:529` 台面板 `plateWithHoles(..., { maxCell: mc(1.0), zBreaks: scoopZBreaks })`（0.15–0.6mm 条带）。
- 两者在台面周边相接；位移后各自的折线走向与法线来源不同 → **接缝读成一条硬边**，
  掠射角下被照亮 = 用户看到的白线（所以随光照/角度变化）。
- 凹槽内暗带/亮灰面 = 凹面做**镜面反射**（暗环境映成暗带），非几何缺陷。
- 虚线锯齿 = 为压住「平底方槽」而塞的 `zBreaks` 加密行留下的网格痕迹。

## 改法（结构性，不是调参）
把「前壁 → 顶部圆角 → 前缘凹槽 → 台面」做成**同一条连续曲面**，删掉位移窗口与解析法线覆写：
1. `bodyProfile` 顶部圆角后**继续向内延伸一段「台面陆桥」**（水平方向 o 增加 ≈6mm、细分 ≥16 段），
   使前缘带由机身扫掠自身产生，不再依赖台面板。
2. 台面板 outline 前缘内缩到陆桥之后（现成约束：触控板前缘 z=101.6、机身前缘 110.6，净距 9mm），
   并把 SCOOP_RAMP 压到陆桥宽度以内。
3. SCOOP 置换改为**只作用于陆桥面**（同一批顶点、同一套法线），或直接**用剖面高度场生成陆桥**
   （彻底不做置换）。
4. 验收机位：`scoopg` / `tpfront` / `hero`（深色预设）三张，改完出图请用户核。
