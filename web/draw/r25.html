MacBook Pro 14″ · 六条反馈逐条修复对照（r25 · commit a98b917）

左=我的页面渲染（photo.html，900–1100px，深色影棚）；右侧为官方/你的参考图。全部数字见 delivery/REPORT-r25-six-fixes.md。

#1 合盖缝（不平齐 / 有间隔）

实测：底座与上盖侧壁 台阶 0.000mm（同一竖直面）；暗缝 0.68mm（官方侧视图实测 0.69mm）。

#2 键盘异常白线

根因是系统性几何 bug：roundedRectOutline 的直边点漏加 cx/cz（只有圆弧点加了），凡是 cz≠0 的轮廓（转轴槽 −107、键盘井 −42.5、栅格…）直边内部点全部落到 z≈0，在机身中部生成横贯“游墙”。修复后该窗口亮像素 108 → 12，键帽侧壁改近黑哑光。

#3 键位偏移（需要左边偏移）

各行首/末修饰键按官方正交俯视图逐键标定对齐：' 1.065→1.0u、tab 1.568→1.5u、caps 1.809→1.75u、lshift 2.312→2.244u…；底行总宽 14.564→14.65u（左侧簇整体左移 0.82mm）。逐键中心对比 Δ 由 +0.40…+0.65mm 收到 ±0.22mm。

#4 正前方凹槽细节

旧版机身路径的前后直边只切 2–3 段（≈100mm/段）→ 凹槽被抹平成柔光斑。roundedRectPath 新增 edgeSegs，机身用 120 段；凹槽改 44mm 宽 / 1.25mm 深 / 平底 + 34% 肩部。

#5 / #6 左右接口细节

细分提高后：USB-C 开口成标准 stadium、内舌可见；MagSafe 5 触点清晰；耳机口正圆。上一轮已把开孔改成“外接矩形 + 四角弧扇”，孔宽实测 8.35mm（开口 8.34mm）。

#7 键盘字母异常变大（回归）

make-kb-legends.py 把字形裁到墨迹 bbox 后，又按原矩形尺寸贴回 → 每个字形被放大 (rect/bbox) 倍。改为按 bbox 占比缩放。官方 top-case 实测单字墨迹 2.75×4.45mm，我的 3.11×4.67mm ✓。
